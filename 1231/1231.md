# 指针
## 概念
指针是一种数据类型 存储其他变量的空间地址,
### 数据类型
- 基本类型
- 组合类型
- 指针
- void
## 定义
类型 * 变量名
```c
    int a;     //1
    char c;    //4
    double g;  //8
//
    int *p1;   //8
    char *p2;  //8
    double *p3;//8
    void *p;// 不能修改指向对象的数据  能够存储任意类型的地址 不能解引用 不能访问 可以类型强制转换进行修改
    


```
rust 取代c++
### * 运算符
- 若在数据类型的后面 * 声明指针类型的变量
- 变量名前面没有数据类型, *解引用 间接运算 指针指向变量的值


## 应用
- 函数参数的传递
- 减小内存开销 浪费
- 数组遍历 操作(指针运算 + ,-)

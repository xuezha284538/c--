## 二、字符串和 vector

### 1. 字符串

在 C 语言中，字符串通常是字符数组：

```c
char str[] = "hello";
char *p = "world";
```

但 C++ 提供了更方便的 `string` 类型。

### 2. C++ 中字符串的优点

- 不需要手动管理内存
- 可以直接比较
- 可以直接拼接
- 有很多方便的方法，如：
  - `size()`：长度
  - `empty()`：是否为空
  - `at()`：访问某个位置

例如：

```cpp
string s1 = "abc";
string s2 = "def";
string s3 = s1 + s2;
```

字符串比较：

```cpp
if (s1 == s2) {
    // 相等
}
```

### 3. 遍历字符串

你学到了几种遍历方式：

```cpp
for (auto r : s1)           // 只读，值拷贝
for (auto &r : s1)          // 引用，可以修改
for (const auto &r : s1)    // 常量引用，安全且常用
for (auto &&r : s1)         // 右值引用，通常用于临时对象
```

小白记忆口诀：

- 只看不改：`const auto &`
- 需要改：`auto &`
- 简单遍历：`auto`

### 4. vector

`vector` 是 C++ 中最常用的容器之一，类似动态数组。

它的优点：

- 大小可以动态增长
- 不需要提前确定大小
- 访问元素方便
- 常用于存放一组数据

例如：

```cpp
vector<int> v;
v.push_back(10);
v.push_back(20);
```

访问：

```cpp
cout << v[0] << endl;
```

## 三、面向对象编程 OOP

这是本次学习的主线。

### 1. 什么是面向对象？

面向对象编程的思想是：

- 把现实中的事物抽象成对象
- 对象有属性和行为
- 把同类对象抽象成类

例如：

- 小猫、黑猫、白猫，都是猫类的对象
- 猫有属性：名字、年龄
- 猫有行为：叫、跑、睡觉

### 2. 类和对象的区别

#### 类

类是“模板”或“蓝图”，描述一类事物共有的特征。

例如：

```cpp
class Cat {
private:
    string name;
    int age;
public:
    void show();
};
```

#### 对象

对象是类的具体实例。

```cpp
Cat c1;
Cat c2("咪咪");
```

类是设计图，对象是房子。

## 五、类的组成

一个类通常包括：

- 属性：成员变量
- 方法：成员函数
- 构造函数：对象创建时自动调用
- 析构函数：对象销毁时自动调用

### 1. 构造函数

构造函数用于初始化对象：

```cpp
class Cat {
public:
    Cat();
    Cat(string name);
    Cat(string name, int age);
};
```

### 2. 析构函数

析构函数用于清理对象资源：

```cpp
~Cat();
```

## 六、封装

封装的意思是：

- 把数据和方法放在一起
- 对外隐藏内部细节
- 通过规定的接口访问对象

例如：

```cpp
class Cat {
private:
    int age;
public:
    int getAge();
    void setAge(int n);
};
```

这样做的好处：

- 安全
- 可以控制访问
- 代码更清晰
- 后期修改方便

---

## 七、继承

继承是面向对象中非常重要的机制。

### 1. 继承的概念

- 父类 / 基类 / 超类：更通用的类
- 子类 / 派生类：从父类继承来的类

例如：

```cpp
class Shape { ... };
class Circle : public Shape { ... };
class Triangle : public Shape { ... };
```

### 2. 继承的好处

- 代码复用
- 更容易维护
- 更容易扩展

### 3. 子类能获得什么

子类可以继承父类中的：

- 受保护成员
- 公有成员
- 也可以拥有自己的成员

### 4. 私有成员的限制

父类中的私有成员，子类不能直接访问。只能通过父类提供的接口去访问。

---

## 八、多态

多态是面向对象编程中最关键的思想之一。

### 1. 什么是多态

同一个行为在不同对象上表现出不同效果。

例如：

- 圆形求面积和三角形求面积方法不同
- 但它们都叫 `area()`

### 2. 你学到的多态类型

#### （1）重载 Overload

同一个类中，同名方法参数不同。

```cpp
int add(int a, int b);
double add(double a, double b);
```

#### （2）重写 Override

子类中重新实现父类方法。

```cpp
class Shape {
public:
    virtual double area() = 0;
};

class Circle : public Shape {
public:
    double area() override {
        return 3.14 * r * r;
    }
};
```

#### （3）虚函数

虚函数的作用是：

- 允许运行时决定调用哪个版本
- 让程序更灵活

### 3. 一个非常重要的注意点

父类的析构函数必须是虚函数，否则对象销毁时可能只调用父类析构函数，导致子类资源没有释放。

## 九、抽象类和接口类

### 1. 抽象类

抽象类至少含有一个纯虚函数。

```cpp
virtual double area() = 0;
```

特点：

- 不能直接实例化
- 一般用于规定“必须实现什么功能”

### 2. 接口类

接口类通常：

- 所有函数都是纯虚函数
- 没有成员属性
- 专门规定行为接口

例如：

```cpp
class USB {
public:
    virtual void plugIn() = 0;
    virtual void run() = 0;
    virtual void pullOut() = 0;
};
```

这种设计的作用是：

- 规定标准
- 让不同类实现统一能力

## 十、组合、聚合、关联

这是类与类之间关系的核心概念。

### 1. 组合（强关系）

整体和部分关系非常强。

例如：

```cpp
class Line {
    Point s;
    Point e;
};
```

特点：

- 线段不能离开两个点而存在
- 整体销毁，部分也会销毁

### 2. 聚合（弱关系）

整体和部分可以相对独立。

```cpp
class Brand {
    vector<Product*> productList;
};
```

特点：

- 部分可以独立存在
- 整体销毁不一定导致部分也马上消失

### 3. 关联

两个对象之间有联系，但不一定是整体与部分。

例如：

- 顾客和订单之间的关系
- 商品和品牌之间的关系

## 十一、static

`static` 是 C++ 中非常常见的关键字。

### 1. static 成员

属于类，而不是某个对象。

所有对象共享同一个变量。

### 2. static 方法

可以通过类名访问，通常用于工具函数。

### 3. 重要点

static 方法不能直接访问普通成员变量，因为它不属于某个对象。

## 十二、设计模式

你也接触到了设计模式，这是“程序设计思想”的高级部分。

### 1. 单例模式 Singleton

特点：

- 一个类只能创建一个实例
- 任何地方拿到的都是同一个对象

实现方式：

- 构造函数私有化
- 提供一个全局入口

例如：

```cpp
class Singleton {
private:
    Singleton() {}
public:
    static Singleton* getInstance() {
        static Singleton instance;
        return &instance;
    }
};
```

用途：

- 日志器
- 配置管理器
- 数据库连接

### 2. 工厂模式 Factory

作用：

- 把对象创建的代码集中管理
- 使用者不需要关心具体实现

例如：

- 返回 Word 对象
- 返回 Excel 对象
- 返回 PDF 对象

好处：

- 扩展方便
- 代码结构更清晰

## 十三、STL：标准模板库

STL 是 C++ 最实用、最常用的标准库之一。

STL 主要分成三块：

- 容器
- 算法
- 迭代器

### 1. 容器

容器就是存放数据的结构。

#### 序列容器

- `vector`：动态数组，最常用
- `array`：固定大小数组
- `list`：双向链表
- `deque`：双端队列

#### 关联容器

- `set`：集合，不重复
- `map`：键值对
- `multimap`：允许重复键

#### 无序关联容器

- `unordered_set`
- `unordered_map`

#### 容器适配器

- `stack`：栈
- `queue`：队列
- `priority_queue`：优先级队列

### 2. 这些容器怎么选

- 需要随机访问：`vector`
- 需要频繁插入删除：`list`
- 要键值映射：`map`
- 要先进后出：`stack`
- 要先进先出：`queue`

这其实就是“数据结构和程序设计”的基础。

## 十四、泛型和模板编程

### 1. 什么是泛型

泛型的意思是：代码可以适用于不同类型。

比如：

- 一个函数可以比较 int 型
- 也可以比较 double 型
- 也可以比较 string 型

### 2. 模板编程

C++ 里最常见的泛型方式是模板。

#### 函数模板

```cpp
template <typename T>
T max(T a, T b) {
    return a > b ? a : b;
}
```

#### 类模板

```cpp
template <typename T>
class Box {
private:
    T data;
public:
    Box(T val) : data(val) {}
    T get() { return data; }
};
```

### 3. 为什么重要

模板让代码可以复用，减少重复写代码。

## 十五、算法和 Lambda

### 1. 算法

STL 里面有很多常见算法：

- `sort()`：排序
- `find_if()`：找到符合条件的元素
- `for_each()`：遍历所有元素

### 2. Lambda 表达式

Lambda 是匿名函数。

```cpp
auto f = [](int a, int b) -> int {
    return a + b;
};

cout << f(2, 3) << endl;
```

Lambda 由四部分组成：

- 捕获列表：`[]`
- 参数列表：`(int a, int b)`
- 返回值：`-> int`
- 函数体：`{ ... }`

例如：

```cpp
sort(v.begin(), v.end(), [](int x, int y) {
    return x > y;
});
```

它的价值在于：

- 不需要额外定义函数
- 代码更简洁
- 非常适合算法参数

# OpenCV 视频的运动探测

## 思路

视频由逐帧的图像构成，图像是由像素构成的矩阵

背景：静态部分
前景：运动部分

步骤
- 通过分析前后帧（两帧、多帧、或是预训练）提取或分离出场景中的背景与前景
- 先把图像灰度化（降低计算量）
- 再二值化（黑白两色）
- 再形态学处理腐蚀、膨胀
- 获得轮廓
- 标记运动区域

## OpenCV 提供运动探测方法

- 帧差法：室内环境
- GMM：室内环境
- KNN：室外复杂环境
- ...

OpenCV 中实现视频运动物体检测的基本原理主要基于**背景建模与前景提取**，核心思想是通过对比视频序列中连续帧之间的差异，识别出与背景不同的运动区域（前景目标）。以下是其基本原理和常用方法：


### 1. 核心原理：背景与前景分离
视频由连续的帧组成，背景通常是相对静止的部分（如墙壁、地面），而运动物体是变化的部分（如行人、车辆）。运动检测的本质是：
- 建立一个**背景模型**（表示场景中静止的部分）
- 对比当前帧与背景模型，找出差异区域（即运动的前景目标）


### 2. 常用实现方法
#### （1）帧差法（Frame Difference）
- **原理**：计算连续两帧或多帧之间的像素差异，通过阈值筛选出变化的区域。
- **步骤**：
  1. 将连续帧转换为灰度图（减少计算量）
  2. 计算帧之间的绝对差值：`diff = |frame(t) - frame(t-1)|`
  3. 对差值图进行阈值处理，得到二值化图像（白色为运动区域，黑色为背景）
  4. 对二值化图像进行形态学操作（腐蚀、膨胀）去除噪声
- **优缺点**：简单快速，但对光照变化敏感，易产生“空洞”或“重影”。

#### （2）混合高斯模型（Gaussian Mixture Model, GMM）
- **原理**：为每个像素建立多个高斯分布模型来表示背景（适应光照变化、动态背景等复杂场景）。
- **步骤**：
  1. 初始化：为每个像素分配多个高斯分布（通常3-5个），代表不同的背景状态
  2. 更新：新帧到来时，判断像素值是否匹配某个高斯分布，匹配则更新该分布参数（均值、方差、权重）
  3. 前景判断：不匹配任何背景高斯分布的像素被标记为前景
- **优缺点**：能适应光照变化和动态背景（如晃动的树叶），但计算量较大。OpenCV 中通过 `cv2.createBackgroundSubtractorMOG2()` 实现。

#### （3）KNN 背景建模（K-Nearest Neighbors）
- **原理**：将像素的历史值作为样本，通过 KNN 算法判断当前像素是否属于背景。
- **步骤**：
  1. 为每个像素存储历史像素值样本集
  2. 计算当前像素与样本集中像素的距离，选择最近的 K 个样本
  3. 根据距离判断当前像素是否为背景（距离过远则为前景）
- **优缺点**：检测精度高，对噪声更鲁棒，OpenCV 中通过 `cv2.createBackgroundSubtractorKNN()` 实现。


### 3. 典型流程
1. **读取视频**：通过 `cv2.VideoCapture` 读取视频帧
2. **预处理**：转为灰度图、高斯模糊（去噪）
3. **背景建模**：使用上述方法生成前景掩码（Foreground Mask）
4. **后处理**：
   - 形态学操作（腐蚀 `erode` 去除小噪声，膨胀 `dilate` 填充空洞）
   - 轮廓检测（`cv2.findContours`）提取运动物体的边界
5. **可视化**：在原视频上绘制运动物体的边界框


### 4. 应用场景
- 安防监控（异常行为检测）
- 交通流量统计
- 行为分析（如行人跟踪）


```c++
// 帧差法
#include <iostream>
#include <opencv2/opencv.hpp>

using namespace cv;
using namespace std;

int main()
{
    // 打开视频或摄像头（0为默认摄像头）
    VideoCapture cap("vtest.avi"); // 替换为视频路径或0
    if (!cap.isOpened())
    {
        cerr << "无法打开视频源！" << endl;
        return -1;
    }

    Mat frame, prevFrame, grayFrame, grayPrev, diff;
    // 读取第一帧作为初始背景
    // 运算符重载、语法糖
    // cap >> prevFrame;
    cap.read(prevFrame);

    cvtColor(prevFrame, grayPrev, COLOR_BGR2GRAY); // 转为灰度图

    while (true)
    {
        cap >> frame;
        if (frame.empty())
            break;

        // 转为灰度图并降噪
        cvtColor(frame, grayFrame, COLOR_BGR2GRAY);
        GaussianBlur(grayFrame, grayFrame, Size(5, 5), 0);

        // 计算当前帧与前一帧的差异
        //
        absdiff(grayFrame, grayPrev, diff);
        // 阈值处理得到二值化前景
        threshold(diff, diff, 30, 255, THRESH_BINARY);

        // 形态学操作：去除噪声
        Mat kernel = getStructuringElement(MORPH_RECT, Size(3, 3));
        erode(diff, diff, kernel);
        dilate(diff, diff, kernel);

        // 查找轮廓并绘制边界框
        vector<vector<Point>> contours;
        findContours(diff, contours, RETR_EXTERNAL, CHAIN_APPROX_SIMPLE);
        for (auto &c : contours)
        {
            if (contourArea(c) < 1000)
                continue; // 过滤小噪声
            Rect bbox = boundingRect(c);
            // 绘制矩形
            rectangle(frame, bbox, Scalar(0, 255, 0), 2);
        }

        // 更新前一帧
        grayPrev = grayFrame.clone();

        // 显示结果
        imshow("result", frame);
        imshow("diff", diff);

        // 按 q 退出
        if (waitKey(30) == 'q')
            break;
    }

    cap.release();
    destroyAllWindows();
    return 0;
}
```

```c++
#include <opencv2/opencv.hpp>
#include <iostream>

using namespace cv;
using namespace std;

int main() {
    // 打开视频文件或摄像头（0表示默认摄像头）
    VideoCapture cap(0); // 替换为视频路径或0使用摄像头
    
    // 检查视频是否成功打开
    if (!cap.isOpened()) {
        cerr << "无法打开视频源！" << endl;
        return -1;
    }

    // 创建MOG2背景减法器
    Ptr<BackgroundSubtractor> pBackSub = createBackgroundSubtractorMOG2();
    
    // 用于形态学操作的核
    // 卷积核（滤波器）
    Mat kernel = getStructuringElement(MORPH_ELLIPSE, Size(3, 3));
    
    Mat frame, fgMask, bgModel;
    
    while (true) {
        // 读取当前帧
        cap >> frame;
        if (frame.empty()) break; // 视频结束
        
        // 对当前帧应用背景减法，得到前景掩码
        pBackSub->apply(frame, fgMask);
        
        // 形态学操作：去除噪声并填充空洞
        erode(fgMask, fgMask, kernel);    // 腐蚀
        dilate(fgMask, fgMask, kernel);   // 膨胀
        
        // 查找前景中的轮廓
        vector<vector<Point>> contours;
        findContours(fgMask, contours, RETR_EXTERNAL, CHAIN_APPROX_SIMPLE);
        
        // 绘制检测到的运动目标边界框
        for (size_t i = 0; i < contours.size(); i++) {
            // 过滤过小的轮廓（排除噪声）
            if (contourArea(contours[i]) < 100) continue;
            
            // 获取轮廓的边界矩形
            Rect boundingRect = cv::boundingRect(contours[i]);
            rectangle(frame, boundingRect, Scalar(0, 255, 0), 2);
            
            // 在框上方显示"运动目标"标签
            putText(frame, "Moving Object", 
                    Point(boundingRect.x, boundingRect.y - 10),
                    FONT_HERSHEY_SIMPLEX, 0.5, Scalar(0, 255, 0), 2);
        }
        
        // 显示结果
        imshow("s", frame);
        imshow("f", fgMask);
        
        // 按下ESC键退出
        char c = (char)waitKey(30);
        if (c == 27) break;
    }
    waitKey();
    // 释放资源
    cap.release();
    destroyAllWindows();
    return 0;
}
```

KNN
```c++
#include <opencv2/opencv.hpp>
#include <iostream>

using namespace cv;
using namespace std;

int main() {
    // 打开视频文件或摄像头（0表示默认摄像头）
    VideoCapture cap(0); // 替换为视频路径或0使用摄像头
    
    // 检查视频是否成功打开
    if (!cap.isOpened()) {
        cerr << "无法打开视频源！" << endl;
        return -1;
    }

    // 创建KNN背景减法器
    // 第一个参数：detectShadows=true 表示检测阴影（阴影会被标记为灰色）
    Ptr<BackgroundSubtractor> pBackSub = createBackgroundSubtractorKNN(true);
    
    // 用于形态学操作的核（去除噪声）
    Mat kernel = getStructuringElement(MORPH_ELLIPSE, Size(3, 3));
    
    Mat frame, fgMask;
    int frameCount = 0;
    
    while (true) {
        // 读取当前帧
        cap >> frame;
        if (frame.empty()) break; // 视频结束
        
        // 对前100帧进行背景模型训练（可选，加速模型收敛）
        if (frameCount < 100) {
            pBackSub->apply(frame, fgMask, 0.001); // 学习率较低，缓慢更新背景
        } else {
            pBackSub->apply(frame, fgMask, -1); // 停止主动学习，自动适应背景变化
        }
        
        // 形态学操作：先腐蚀去除小噪声，再膨胀恢复目标形态
        erode(fgMask, fgMask, kernel);
        dilate(fgMask, fgMask, kernel);
        
        // 进一步处理：去除阴影（KNN会将阴影标记为灰色(127)，这里将其转为背景）
        threshold(fgMask, fgMask, 250, 255, THRESH_BINARY);
        
        // 查找前景中的轮廓
        vector<vector<Point>> contours;
        findContours(fgMask, contours, RETR_EXTERNAL, CHAIN_APPROX_SIMPLE);
        
        // 绘制运动目标边界框
        for (size_t i = 0; i < contours.size(); i++) {
            // 过滤过小的轮廓（排除噪声）
            if (contourArea(contours[i]) < 800) continue;
            
            // 获取边界矩形
            Rect bbox = boundingRect(contours[i]);
            rectangle(frame, bbox, Scalar(0, 0, 255), 2);
            
            // 显示目标信息
            putText(frame, "Moving: " + to_string(contourArea(contours[i])),
                    Point(bbox.x, bbox.y - 10),
                    FONT_HERSHEY_SIMPLEX, 0.5, Scalar(0, 0, 255), 2);
        }
        
        // 显示结果
        imshow("s", frame);
        imshow("knn", fgMask);
        
        // 按下ESC键退出
        char c = (char)waitKey(30);
        if (c == 27) break;
        
        frameCount++;
    }
    
    // 释放资源
    cap.release();
    destroyAllWindows();
    return 0;
}
```

# 树

## 树的基本概念
树是一种非线性数据结构，由n（n≥0）个节点组成的有限集合。当n=0时，称为空树；当n>0时，有一个特定的称为根的节点，其余节点可分为m（m≥0）个互不相交的有限集合，每个集合本身又是一棵树，称为根的子树。

### 树的相关术语
- **节点**：树中的每个元素
- **根节点**：没有父节点的节点
- **叶子节点**：没有子节点的节点
- **父节点**：有子节点的节点
- **子节点**：被父节点直接包含的节点
- **兄弟节点**：具有相同父节点的节点
- **节点的度**：节点拥有的子树数目
- **树的度**：树中节点的最大度数
- **深度**：从根节点到该节点的路径长度
- **高度**：从该节点到最远叶子节点的路径长度
- **层次**：从根节点开始，根为第1层，依次递增

## 树的分类

### 按节点度数分类
- **二叉树**：每个节点最多有两个子节点
- **三叉树**：每个节点最多有三个子节点
- **多叉树**：每个节点可以有多个子节点

### 按树的结构分类
- **有序树**：子树之间有顺序关系
- **无序树**：子树之间无顺序关系
- **完全树**：除最后一层外，其他层的节点数都是满的，最后一层的节点从左到右依次排列
- **满树**：每一层的节点数都是最大的

## 二叉树

### 二叉树的定义
二叉树是一种特殊的树，每个节点最多有两个子节点，分别称为左子节点和右子节点。

### 二叉树的性质
1. 在二叉树的第i层上最多有2^(i-1)个节点（i≥1）
2. 深度为k的二叉树最多有2^k - 1个节点（k≥1）
3. 对任何一棵二叉树，若叶子节点数为n0，度为2的节点数为n2，则n0 = n2 + 1
4. 具有n个节点的完全二叉树的深度为⌊log2n⌋ + 1

### 二叉树的存储结构

#### 顺序存储结构
使用数组存储二叉树的节点，按照层次遍历的顺序存储。

```c
#define MAX_SIZE 100

// 顺序存储结构
typedef struct {
    int data[MAX_SIZE];
    int length;
} SeqBinaryTree;
```

#### 链式存储结构
使用指针存储二叉树的节点，每个节点包含数据域和两个指针域。

```c
// 链式存储结构
typedef struct Node {
    int data;
    struct Node *left;
    struct Node *right;
} Node, *BinaryTree;
```

### 二叉树的遍历

#### 前序遍历（根-左-右）
```c
void preOrder(BinaryTree root) {
    if (root != NULL) {
        printf("%d ", root->data);
        preOrder(root->left);
        preOrder(root->right);
    }
}
```

#### 中序遍历（左-根-右）
```c
void inOrder(BinaryTree root) {
    if (root != NULL) {
        inOrder(root->left);
        printf("%d ", root->data);
        inOrder(root->right);
    }
}
```

#### 后序遍历（左-右-根）
```c
void postOrder(BinaryTree root) {
    if (root != NULL) {
        postOrder(root->left);
        postOrder(root->right);
        printf("%d ", root->data);
    }
}
```

#### 层次遍历
```c
void levelOrder(BinaryTree root) {
    if (root == NULL) return;
    
    Node *queue[MAX_SIZE];
    int front = 0, rear = 0;
    queue[rear++] = root;
    
    while (front < rear) {
        Node *current = queue[front++];
        printf("%d ", current->data);
        
        if (current->left != NULL) {
            queue[rear++] = current->left;
        }
        if (current->right != NULL) {
            queue[rear++] = current->right;
        }
    }
}
```

### 二叉树的基本操作

#### 创建二叉树
```c
BinaryTree createNode(int data) {
    Node *newNode = (Node *)malloc(sizeof(Node));
    newNode->data = data;
    newNode->left = NULL;
    newNode->right = NULL;
    return newNode;
}

BinaryTree createBinaryTree() {
    int data;
    printf("请输入节点数据（-1表示空节点）: ");
    scanf("%d", &data);
    
    if (data == -1) {
        return NULL;
    }
    
    Node *root = createNode(data);
    printf("创建左子树（%d的左孩子）: ", data);
    root->left = createBinaryTree();
    printf("创建右子树（%d的右孩子）: ", data);
    root->right = createBinaryTree();
    
    return root;
}
```

#### 计算二叉树的深度
```c
int getDepth(BinaryTree root) {
    if (root == NULL) {
        return 0;
    }
    int leftDepth = getDepth(root->left);
    int rightDepth = getDepth(root->right);
    return leftDepth > rightDepth ? leftDepth + 1 : rightDepth + 1;
}
```

#### 计算二叉树的节点数
```c
int getNodeCount(BinaryTree root) {
    if (root == NULL) {
        return 0;
    }
    return 1 + getNodeCount(root->left) + getNodeCount(root->right);
}
```

#### 计算二叉树的叶子节点数
```c
int getLeafCount(BinaryTree root) {
    if (root == NULL) {
        return 0;
    }
    if (root->left == NULL && root->right == NULL) {
        return 1;
    }
    return getLeafCount(root->left) + getLeafCount(root->right);
}
```

## 二叉搜索树

### 二叉搜索树的定义
二叉搜索树（Binary Search Tree，BST）是一种特殊的二叉树，满足以下性质：
- 左子树的所有节点的值都小于根节点的值
- 右子树的所有节点的值都大于根节点的值
- 左子树和右子树也都是二叉搜索树

### 二叉搜索树的操作

#### 查找
```c
Node* search(BinaryTree root, int key) {
    if (root == NULL || root->data == key) {
        return root;
    }
    if (key < root->data) {
        return search(root->left, key);
    } else {
        return search(root->right, key);
    }
}
```

#### 插入
```c
Node* insert(BinaryTree root, int key) {
    if (root == NULL) {
        return createNode(key);
    }
    if (key < root->data) {
        root->left = insert(root->left, key);
    } else if (key > root->data) {
        root->right = insert(root->right, key);
    }
    return root;
}
```

#### 删除
```c
Node* findMin(BinaryTree root) {
    while (root->left != NULL) {
        root = root->left;
    }
    return root;
}

Node* deleteNode(BinaryTree root, int key) {
    if (root == NULL) {
        return root;
    }
    if (key < root->data) {
        root->left = deleteNode(root->left, key);
    } else if (key > root->data) {
        root->right = deleteNode(root->right, key);
    } else {
        // 情况1：叶子节点
        if (root->left == NULL && root->right == NULL) {
            free(root);
            return NULL;
        }
        // 情况2：只有一个子节点
        else if (root->left == NULL) {
            Node *temp = root->right;
            free(root);
            return temp;
        }
        else if (root->right == NULL) {
            Node *temp = root->left;
            free(root);
            return temp;
        }
        // 情况3：有两个子节点
        Node *temp = findMin(root->right);
        root->data = temp->data;
        root->right = deleteNode(root->right, temp->data);
    }
    return root;
}
```

## 平衡二叉树

### 平衡二叉树的定义
平衡二叉树（AVL树）是一种特殊的二叉搜索树，满足以下性质：
- 左子树和右子树的高度差不超过1
- 左子树和右子树也都是平衡二叉树

### 平衡因子
平衡因子 = 左子树高度 - 右子树高度

### 平衡操作

#### 左旋
```c
Node* leftRotate(Node* z) {
    Node* y = z->right;
    Node* T2 = y->left;
    
    y->left = z;
    z->right = T2;
    
    // 更新高度
    updateHeight(z);
    updateHeight(y);
    
    return y;
}
```

#### 右旋
```c
Node* rightRotate(Node* z) {
    Node* y = z->left;
    Node* T3 = y->right;
    
    y->right = z;
    z->left = T3;
    
    // 更新高度
    updateHeight(z);
    updateHeight(y);
    
    return y;
}
```

## 树的应用

1. **文件系统**：使用树结构组织文件和目录
2. **数据库索引**：B树、B+树等用于数据库索引
3. **表达式解析**：二叉树用于表达式的存储和计算
4. **决策树**：用于机器学习和数据挖掘
5. ** Huffman编码**：用于数据压缩
6. **网络路由**：路由表的组织和查找
7. **游戏开发**：游戏场景的管理和AI决策

## 时间复杂度分析

| 操作 | 二叉树 | 二叉搜索树 | 平衡二叉树 |
|------|--------|------------|------------|
| 查找 | O(n) | O(logn) 平均，O(n) 最坏 | O(logn) |
| 插入 | O(n) | O(logn) 平均，O(n) 最坏 | O(logn) |
| 删除 | O(n) | O(logn) 平均，O(n) 最坏 | O(logn) |
| 遍历 | O(n) | O(n) | O(n) |

## 总结
树是一种重要的数据结构，广泛应用于计算机科学的各个领域。不同类型的树结构适用于不同的场景，如二叉搜索树适用于需要频繁查找的场景，平衡二叉树适用于需要保持较高查询效率的场景。

通过合理选择和使用树结构，可以大大提高算法的效率和程序的性能。

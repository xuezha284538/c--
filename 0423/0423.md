# 图论基础

## 一、图的基本概念

### 1. 图的定义
图 G = (V, E)
- V (Vertex)：顶点集合
- E (Edge)：边的集合

### 2. 图的分类
- **无向图**：边没有方向，(u, v) = (v, u)
- **有向图**：边有方向，<u, v> ≠ <v, u>
- **加权图**：边带有权重
- **稀疏图**：边数远小于 V²
- **稠密图**：边数接近 V²

---

## 二、邻接矩阵表示

### 邻接矩阵定义
用二维数组表示顶点之间的连接关系：
- `adj[i][j] = 1`：顶点 i 和 j 之间有边
- `adj[i][j] = 0`：顶点 i 和 j 之间无边

### 作业示例

**无向图**: G = (V, E)
- V = {A, B, C, D, E, F}
- E = {(A,B), (A,E), (A,C), (B,E), (C,F), (F,D), (E,D)}

**顶点索引映射**:
| 顶点 | 索引 |
|------|------|
| A | 0 |
| B | 1 |
| C | 2 |
| D | 3 |
| E | 4 |
| F | 5 |

**6×6 邻接矩阵**:
```
      A  B  C  D  E  F
    ┌─────────────────┐
A   │ 0  1  1  0  1  0 │
B   │ 1  0  0  0  1  0 │
C   │ 1  0  0  0  0  1 │
D   │ 0  0  0  0  1  1 │
E   │ 1  1  0  1  0  0 │
F   │ 0  0  1  1  0  0 │
    └─────────────────┘
```

## 三、深度优先搜索（DFS）

### 1. 递归实现

**核心思想**：从起始顶点出发，尽可能深地访问顶点，直到无法继续，然后回溯。

**算法步骤**：
1. 访问当前顶点
2. 标记为已访问
3. 递归访问所有未访问的邻接点

**代码实现**（递归）：
```c
void dfs_recursive(int adj[][6], int visited[], int v, int n) {
    printf("%c ", 'A' + v);  // 访问顶点
    visited[v] = 1;          // 标记已访问
    
    for (int i = 0; i < n; i++) {
        if (adj[v][i] == 1 && !visited[i]) {
            dfs_recursive(adj, visited, i, n);  // 递归访问邻接点
        }
    }
}
```

### 2. 栈实现（非递归）

**算法步骤**：
1. 将起始顶点压入栈
2. 弹出栈顶顶点，访问并标记
3. 将所有未访问的邻接点压入栈
4. 重复直到栈为空

**代码实现**（栈）：
```c
void dfs_stack(int adj[][6], int start, int n) {
    int stack[6], top = -1;
    int visited[6] = {0};
    
    stack[++top] = start;
    visited[start] = 1;
    
    while (top >= 0) {
        int v = stack[top--];
        printf("%c ", 'A' + v);
        
        // 逆序入栈，保证输出顺序与递归一致
        for (int i = n - 1; i >= 0; i--) {
            if (adj[v][i] == 1 && !visited[i]) {
                stack[++top] = i;
                visited[i] = 1;
            }
        }
    }
}
```

**DFS 遍历结果**（从 A 开始）：
```
A → B → E → D → F → C
```

## 四、广度优先搜索（BFS）

### 队列实现

**核心思想**：从起始顶点出发，按层次顺序访问所有顶点。

**算法步骤**：
1. 将起始顶点入队
2. 出队并访问顶点
3. 将所有未访问的邻接点入队
4. 重复直到队列为空

**代码实现**（队列）：
```c
void bfs_queue(int adj[][6], int start, int n) {
    int queue[6], front = 0, rear = 0;
    int visited[6] = {0};
    
    queue[rear++] = start;
    visited[start] = 1;
    
    while (front < rear) {
        int v = queue[front++];
        printf("%c ", 'A' + v);
        
        for (int i = 0; i < n; i++) {
            if (adj[v][i] == 1 && !visited[i]) {
                queue[rear++] = i;
                visited[i] = 1;
            }
        }
    }
}
```

**BFS 遍历结果**（从 A 开始）：
```
A → B → C → E → F → D
```

## 五、DFS 与 BFS 对比

| 特性 | DFS | BFS |
|------|-----|-----|
| 数据结构 | 栈 | 队列 |
| 策略 | 深度优先 | 广度优先 |
| 空间复杂度 | O(V) | O(V) |
| 时间复杂度 | O(V+E) | O(V+E) |
| 应用 | 拓扑排序、强连通分量 | 最短路径（无权图）、连通性检测 |

## 六、完整示例代码

```c
#include <stdio.h>

// 邻接矩阵
int graph[6][6] = {
    {0, 1, 1, 0, 1, 0},  // A
    {1, 0, 0, 0, 1, 0},  // B
    {1, 0, 0, 0, 0, 1},  // C
    {0, 0, 0, 0, 1, 1},  // D
    {1, 1, 0, 1, 0, 0},  // E
    {0, 0, 1, 1, 0, 0}   // F
};

void dfs_recursive(int adj[][6], int visited[], int v, int n);
void dfs_stack(int adj[][6], int start, int n);
void bfs_queue(int adj[][6], int start, int n);

int main() {
    int visited[6] = {0};
    
    printf("DFS (递归): ");
    dfs_recursive(graph, visited, 0, 6);
    printf("\n");
    
    printf("DFS (栈): ");
    dfs_stack(graph, 0, 6);
    printf("\n");
    
    printf("BFS (队列): ");
    bfs_queue(graph, 0, 6);
    printf("\n");
    
    return 0;
}
```

**输出结果**：
```
DFS (递归): A B E D F C 
DFS (栈): A B E D F C 
BFS (队列): A B C E F D 
```


# pthread 线程
## 线程的生命周期
- 新建 pthread_create
- 就绪 os任务调度决定 获得cpu的时间片
- 运行  1.结束 2.就绪 3.阻塞
- 阻塞  到就绪   sleep 主动让出cpu时间片 不能获得时间片 wait,
- 结束

## 分离态与非分离态
- datach 分离态,子线程与主线程分离 不可join 不返回数据 任务结束自动释放资源
- join 非分离态(默认) pthread_join() 若不join会出现僵死线程
-  
### 非分离态
```c
    int main()
{
    //创建子线程
    pthread_create();
    //其它语句
    code 1
    pthread_join(t1);//等待子线程t1结束,并获得t1的返回值
    code 2
    code 3

    //结束当前(主)线程 子线程t1可以继续执行 进程未结束前t1 成为僵死线程状态
    pthread_exit(NULL)//结束当前线程
    return 0; //结束进程 所以资源消毁 包括 t1
}

```


## 线程与进程
进程：程序一次执行过程，及在这个过程中获得cpu,内存，文件，网路等资源
一个程序运行默认一个进程 ，但可以创建多个子进程
每个进程的资源是相互隔离的
线程：是进程中的执行单元，一个进程中默认存在一个主线程
    可以创建多个子线程，多个线程可以共享进程中的资源

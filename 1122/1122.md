# C 语言编程

## 概述

1972 丹尼斯里奇基于 B 语言开发 UNIX 过程中设计了 C 语言
目标：简洁、高效控制硬件，实现系统编程

### 语言的发展（标准）
- 1978 出版《C Programming Language》K&B (经典 C)
- C89/90 ASNI C (第一个国际标准)
- C99：局部变量、bool、线程
- C11：修复缺陷
- C17：并发编程
- C23：新特性

### 语言类型

#### 静态与动态
静态类型：C、C++, Java
动态类型：Python、JS

```c
    int     a;  // 4
    double  b;  // 8

    a = 123;
    a = "hello";    // 错误

    let     a;
    let     b;

    a = 23;
    a = "hello";
    a = {1,2,3,"abc", false};
    a = (x, y) => {return x > y ? x : y};

```

#### 编译型与解释型

编译型：C, C++, Java    -> 二进制执行文件
解释型：Python, JS, Java   -> 源代码直接跑虚拟机

## 数据类型

### 字段（标识符）

字段(标识符)
- 常量：`const`, 宏定义
- 变量：数据会改变

标识符的命名规则
- 字母
- 数字
- 下划线
- 不能数字开头、不能包含空格及其他符号
- 不能使用关键字和保留字

正确
- `a`
- `_a`
- `__a6`
- `age`
- `first_name`
- `firstName`
- `FIRST_NAME`

错误
- `6a`  a6
- `first name`  first_name
- `first-name`  first_name
- `int`
- `goto`

### 数据类型

C 语言没有定义基本类型的长度，有平台和编译器决定

- 基本类型（64位系统）
    - `char`        整数、字符 'a'; 1byte
    - `short`       short int; 2byte
    - `int`         整数; 4byte
    - `long`        long int; `win 4byte, linux 8byte`
    - `long long`   long long int; 8byte
    - `float`       单精度浮点，4byte，3.14f, 9.8F
    - `double`      双精度，8byte
    - `long double` 浮点，`win 8, linux 16`
    - `_Bool`       布尔，逻辑真假，1byte；true 1, false 0
    - `bool`        导入头文件 stdbool.h，c23 开始不用导入
- 组合类型
    - 数组
    - 结构体
    - 联合体
    - 枚举
    - `类` C 没有，C++ 包含
- 指针类型
    - `*` 存储内存地址
- void 类型
    - void

# 数据结构与算法

## 栈（LIFO）
栈是一种后进先出（Last-In-First-Out，LIFO）的数据结构，只能在栈顶进行插入和删除操作。

### 栈的实现（顺序栈）
```c
#include <stdio.h>
#include <stdlib.h>
#include <stdbool.h>
#define max 9

// 数据结构
typedef struct stack
{
    char data[max]; // 顺序表
    int top;        // 栈顶指针

} stack;

// 操作
void init(stack *s);
void push(stack *s, char);
char pop(stack *s);
int top(stack *s);
void clean(stack *s);
bool empty(stack *s);
void show(stack *s);
```

### 栈的操作函数

#### 初始化栈
```c
void init(stack *s)
{
    s->top = -1;
}
```

#### 入栈
```c
void push(stack *s, char ch)
{
    if (s->top == max - 1)
    {
        return;
    }
    s->top++;
    s->data[s->top] = ch;
}
```

#### 出栈
```c
char pop(stack *s)
{
   if (s->top == max - 1)
    {
        return EXIT_FAILURE;
    }

    return  s->data[s->top--] = 0;
}
```

#### 获取栈顶元素
```c
int top(stack *s)
{
    return s->data[s->top];
}
```

#### 清空栈
```c
void clean(stack *s)
{
    s->top=-1;
}
```

#### 判断栈是否为空
```c
bool empty(stack *s)
{
   return s->top==-1;
}
```

#### 显示栈内容
```c
void show(stack *s)
{
    printf("{");
    for(int i=s->top;i>=0;i--)
    {
        printf("%c,",s->data[i]);
    }
    printf("}\b\n");
}
```

#### 主函数示例
```c
int main()
{
    stack s;
    init(&s);
    push(&s, 'a');
    push(&s, '3');
    push(&s, 'a');
    push(&s, 'a');
    push(&s, 'd');
    push(&s, 'c');
    push(&s, 'b');
    pop(&s);
    printf("%c\n",top(&s));
    show(&s);
}
```

## 单链表回文判断
回文是指正着读和倒着读都一样的字符串。

### 单链表结构
```c
typedef struct Node
{
    char data;         // 数据域
    struct Node *next; // 指针域
} Node, node;

typedef struct // 最小单链表 头节点加尾指针
{
    Node *head;
    Node *r;
    int length;
} linkedlist;
```

### 核心算法：快慢指针找中点 + 链表翻转
```c
// 快慢指针找中点
node *mid(node *p)
{
    Node *slow = p;
    Node *fast = p->next;

    while (fast != NULL && fast->next != NULL)
    {
        slow = slow->next;
        fast = fast->next->next; // 走俩步
    }
    return slow;
}

// 翻转链表
node *revers(node *p)
{
    node *crr = p;
    node *prev = NULL;
    node *next = NULL;
    while (crr)
    {
        next = crr->next;
        crr->next = prev;
        prev = crr;
        crr = next;
    }
    return prev;
}

// 判断回文
void is(linkedlist *p)
{
    // 边界条件检查
    if (p->head->next == NULL || p->head->next->next == NULL)
    {
        printf("是回文\n");
        return;
    }

    int is = 1;
    node *mnode = mid(p->head->next);
    node *after = revers(mnode->next);
    node *afterCopy = after; // 保存翻转后的指针用于恢复
    node *before = p->head->next;

    while (after != NULL)
    {
        if (before->data != after->data)
        {
            is = 0;
            break;
        }
        before = before->next;
        after = after->next;
    }

    // 恢复原链表结构
    mnode->next = revers(afterCopy);

    if (is)
    {
        printf("是回文\n");
    }
    else
    {
        printf("不是回文\n");
    }
}
```

## 荷兰国旗问题
荷兰国旗问题是一个经典的排序问题，要求将包含0、1、2的数组排序，使得所有0在最左边，1在中间，2在最右边。

### 解决方案
```c
void swap(int *p, int *p1)
{
    int temp = *p1;
    *p1 = *p;
    *p = temp;
}

void show(int ch[], int len)
{
    printf("{");
    for (int i = 0; i < len; i++)
    {
        printf("%d,", ch[i]);
    }
    printf("\b}\n");
}

int main()
{
    int ch[] = {1, 2, 0, 0, 1, 2, 2, 0, 1, 2, 0, 1};
    int len = sizeof(ch) / sizeof(ch[0]);
    int r = 0; // 红色指针（0的边界）
    int w = 0; // 白色指针（当前元素）
    int b = len - 1; // 蓝色指针（2的边界）
    
    while (w <= b)
    {
        if (ch[w] == 0)
        {
            swap(&ch[w], &ch[r]);
            r++;
            w++;
        }
        else if (ch[w] == 1)
        {
            w++;
        }
        else
        {
            swap(&ch[w], &ch[b]);
            b--;
        }
    }

    show(ch, len);
    return 0;
}
```

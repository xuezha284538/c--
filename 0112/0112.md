## void *
通用指针 
- 可以接受任意类型的指针的值 
- 不能解引用
- 强制转换其他具体类型 在解引用
void * 不是空指针

空指针: 是  任意类型 *p=NULL
野指针: 没有初始化  int *p; 或者被free 释放掉的  不确定行为
```c
    char c;
    int  i;
    //具体指针
    char *p = &c;
    int  *p1 = &i;
    // 空指针
    void *p2;

    p2=p1; //void 可以指向char
    p2=p;  //void 可以指向int
           //           long , short ,float 等等

    //解引用
    *p2=123; //错误

    int *p3 =(int*)p2;//正确
    *p3=112; 


```
## 流程
1. 使用malloc分配空间
2. 若空间不足 使用realloc 重新分配    重新接收 ptr=realloc(ptr,size)
3. 必须使用free 释放堆内存 释放后变成悬空指针(可能记住原地址)  建议ptr=NULL; 赋值空指针 避免修改原数据  
4. calloc() 等价于 *p=malloc() memset(p,0,size)

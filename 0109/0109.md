# 字符串

## 定义

字符串：字符的序列

实现
- 字符数组
- 字符指针

```c
    // 字符数组，**不**是字符串
    char s1[] = {'h','e','l','l','o'};
    // 字符数组，字符串
    char s2[] = {'h','e','l','l','o','\0'};

    char s3[] = "hello";
    char *s4 = "hello";

```

## 区分 字符数组与字符指针

```c
    // 数组是一个指针常量
    char s1[] = "hello";    // 6
    // s1 = "bye";
    // strcpy
    // s1[0] = 'b';
    // s1[1] = 'y';
    // s1[2] = 'e';
    // s1[3] = '\0';
    // s1[4] = '\0';
    // s1[5] = '\0';
    printf("%s\n", s1);

    // 指针变量，可以指向其他地址空间
    // 字符串常量，不可变
    char *s2 = "hello";
    s2 = "bye";
    // s2[0] = 'B';
    printf("%s\n", s2);

```

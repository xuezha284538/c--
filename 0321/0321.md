# 链式存储（Linked Storage）

## 链式存储的定义

**链式存储**是一种非连续的存储方式，它通过指针将分散存储的数据元素链接起来，形成一个逻辑上连续的数据结构。链式存储是实现链表的基础。

## 链式存储的特点

1. **非连续存储**：数据元素在内存中可以分散存储
2. **指针链接**：通过指针将各个节点链接起来
3. **动态分配**：可以根据需要动态分配内存
4. **灵活性**：插入和删除操作不需要移动元素
5. **空间开销**：每个节点需要额外的指针空间

## 链表的基本结构

链表中的每个元素称为**节点**（Node），每个节点包含两个部分：

1. **数据域**：存储数据元素的值
2. **指针域**：存储指向下一个节点的指针

### 单链表节点结构

```c
typedef struct Node {
    int data;           // 数据域
    struct Node *next;  // 指针域，指向下一个节点
} Node, *LinkList;
```

## 链表的分类

### 1. 单链表（Singly Linked List）

**定义**：每个节点只有一个指针指向下一个节点。

**特点**：
- 只能从表头遍历到表尾
- 查找效率较低，需要从头开始遍历
- 插入和删除操作比较简单

**C语言实现示例**：

```c
#include <stdio.h>
#include <stdlib.h>

typedef struct Node {
    int data;
    struct Node *next;
} Node, *LinkList;

// 创建空链表
void InitList(LinkList *L) {
    *L = (LinkList)malloc(sizeof(Node));
    (*L)->next = NULL;  // 头节点的next指针为NULL
}

// 创建链表（尾插法）
void CreateList(LinkList L, int n) {
    LinkList r = L;  // r指向链表的尾节点
    for (int i = 0; i < n; i++) {
        LinkList p = (LinkList)malloc(sizeof(Node));
        printf("请输入第%d个元素: ", i + 1);
        scanf("%d", &p->data);
        p->next = NULL;
        r->next = p;
        r = p;
    }
}

// 插入元素
int InsertList(LinkList L, int i, int e) {
    LinkList p = L;
    int j = 0;
    while (p && j < i - 1) {  // 找到第i-1个节点
        p = p->next;
        j++;
    }
    if (!p || j > i - 1) return 0;  // 插入位置不合理
    LinkList s = (LinkList)malloc(sizeof(Node));
    s->data = e;
    s->next = p->next;
    p->next = s;
    return 1;
}

// 删除元素
int DeleteList(LinkList L, int i, int *e) {
    LinkList p = L, q;
    int j = 0;
    while (p->next && j < i - 1) {  // 找到第i-1个节点
        p = p->next;
        j++;
    }
    if (!p->next || j > i - 1) return 0;  // 删除位置不合理
    q = p->next;
    p->next = q->next;
    *e = q->data;
    free(q);
    return 1;
}

// 查找元素位置
int LocateElem(LinkList L, int e) {
    LinkList p = L->next;
    int i = 1;
    while (p) {
        if (p->data == e) return i;
        p = p->next;
        i++;
    }
    return 0;  // 未找到
}

// 遍历链表
void TraverseList(LinkList L) {
    LinkList p = L->next;
    while (p) {
        printf("%d ", p->data);
        p = p->next;
    }
    printf("\n");
}

int main() {
    LinkList L;
    InitList(&L);
    CreateList(L, 5);
    printf("创建的链表: ");
    TraverseList(L);
    
    InsertList(L, 3, 100);
    printf("插入元素后: ");
    TraverseList(L);
    
    int e;
    DeleteList(L, 4, &e);
    printf("删除的元素: %d\n", e);
    printf("删除元素后: ");
    TraverseList(L);
    
    int pos = LocateElem(L, 100);
    printf("元素100的位置: %d\n", pos);
    
    return 0;
}
```

### 2. 双链表（Doubly Linked List）

**定义**：每个节点有两个指针，分别指向前一个节点和后一个节点。

**特点**：
- 可以双向遍历
- 查找效率比单链表高
- 插入和删除操作需要修改两个指针

**双链表节点结构**：

```c
typedef struct DNode {
    int data;
    struct DNode *prior;  // 指向前一个节点
    struct DNode *next;   // 指向下一个节点
} DNode, *DLinkList;
```

### 3. 循环链表（Circular Linked List）

**定义**：链表的最后一个节点指向第一个节点，形成一个环。

**特点**：
- 可以从任何节点开始遍历整个链表
- 适用于需要循环访问的场景

## 链式存储与顺序存储的比较

| 特性 | 链式存储 | 顺序存储 |
|------|----------|----------|
| **存储方式** | 非连续存储 | 连续存储 |
| **内存分配** | 动态分配 | 静态分配 |
| **访问方式** | 顺序访问（O(n)） | 随机访问（O(1)） |
| **插入操作** | O(1)（已知位置） | O(n) |
| **删除操作** | O(1)（已知位置） | O(n) |
| **空间利用率** | 有指针开销 | 可能有空间浪费 |
| **扩容** | 无需扩容 | 需要重新分配内存 |
| **实现复杂度** | 较复杂 | 较简单 |

## 链式存储的时间复杂度分析

### 单链表操作时间复杂度

| 操作 | 时间复杂度 |
|------|------------|
| 查找元素 | O(n) |
| 插入元素 | O(1)（已知位置） |
| 删除元素 | O(1)（已知位置） |
| 遍历链表 | O(n) |
| 求链表长度 | O(n) |

## 链式存储的应用场景

1. **动态数据结构**：数据量不确定，需要频繁插入和删除
2. **栈和队列**：可以用链表实现栈和队列
3. **图的表示**：可以用邻接表表示图
4. **哈希表**：处理哈希冲突的链表法
5. **内存管理**：操作系统中的内存分配
6. **多项式表示**：用链表表示稀疏多项式

## 链式存储的优缺点

### 优点

1. **灵活性高**：插入和删除操作不需要移动元素
2. **动态分配**：可以根据需要动态分配内存
3. **空间利用**：只分配实际需要的内存空间
4. **避免内存浪费**：不会有未使用的内存空间

### 缺点

1. **访问效率低**：只能顺序访问，不能随机访问
2. **空间开销**：每个节点需要额外的指针空间
3. **实现复杂**：需要处理指针操作，容易出错
4. **缓存不友好**：节点分散存储，缓存命中率低

## 总结

链式存储是一种重要的存储方式，它通过指针将分散存储的节点链接起来，形成一个逻辑上连续的数据结构。链式存储具有灵活性高、动态分配等优点，但也存在访问效率低、空间开销大等缺点。在实际应用中，需要根据具体需求选择合适的存储方式。

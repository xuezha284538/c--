## 事务处理 关系型数据库 非常重要特性

事务:一个业务操作包含多个数据操作 DML 这多个数据操作在逻辑层是一个整体,它的执行撤销回滚被称为一个事务:包含四个特性:原子性 一致性 隔离性 持久性
A C I D
- 原子性 构成事务的多个数据操作是一个整体 不可分割 它的执行要么成功要么回滚
- 一致性 事务执行前后,数据值是一致的
- 隔离性 事务执行期间,多个事务相互隔离 隔离级别 : 读未提交 读已提交 可重复读 串行化
- 持久性 事务结束 数据写入磁盘

### 隔离级别
| 隔离级别 | `脏读` | `不可重复读` | `幻读` |
| -------- | ------ | ------------ | ------ |
| 读未提交 | +      | +            | +      |
| 读已提交 | -      | +            | +      |
| 可重复读 | -      | -            | +      |
| 串行化   | -      | -            | -      |

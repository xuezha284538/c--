# 指针 数组 字符串

## 指针
```c
    // * &
    int a;
     //1) 声明指针类型的变量 2) 解引用 访问指针指向的空间  
    int *p; 

    //&取地址
    p=&a;
    //间接修改 解引用 
    *p = 3;
    int x = *p;
    //不能对野指针进行解引用      
    char *p2;
    //*p2='a';

    
```
### 野指针
- 声明后 未初始化 未赋值
- 动态内存分配 malloc空间 释放free后 也为野指针

避免野指针
- 声明时进行初始化
- 声明时赋值 null (0)
- 

### 空指针
- 解引用前进行非null 判断
- 初始化时 赋值NULL
- 动态内存管理 free 之后 赋值NULL

同:都不能解引用
异:野指针是不确定的值 空指针时确定的值

### 指针的运算 (地址的偏移 单位为数据类型)
- 指针加法
- 指针减法
- 俩个指针相减  如果是指向同一个数组不同元素 结果为偏移量 

```c
    int a[];
    int *p=a;
    a++;// 错误
    p++;//正确



```
## 常量指针 指针常量
```c
    //常量指针 指向的内容 值不可变
    const int *p;

    //指针常量 地址不可变
    int *const p;


```

# Video Motion Detection System

实时视频采集与运动检测系统 —— 基于 C++ 和 OpenCV,支持帧差法与 MOG2 双模式,采集与处理多线程分离。

## 功能特性

- 🎥 **视频采集**: 支持 USB 摄像头实时采集
- 📹 **视频录制**: 支持 MP4/AVI/H.264/H.265 多编码格式
- 🔍 **运动检测**:
  - **帧差法**: 代码量小、计算量低,适合嵌入式等资源受限场景
  - **MOG2 混合高斯背景建模**: 精度更高,适应光照变化与动态背景
- 🧵 **多线程架构**: 采集-处理分离的生产者-消费者模型,提升吞吐量
- 📊 **实时监控**: FPS 显示 + 目标计数 + 前景掩码可视化
- ⚙️ **参数可配置**: 命令行参数控制摄像头、检测模式、最小面积、录制文件

## 技术架构

```
采集线程(生产者) → FrameQueue → 处理线程(消费者)
                          ↓
                MotionDetector (帧差法/MOG2)
                          ↓
                     VideoRecorder (可选)
                          ↓
                       imshow 显示
```

**图像处理管线**: 灰度化 → 高斯滤波 → 二值化 → 形态学处理 → 轮廓检测 → 面积过滤 → 边界框标注

## 编译

### 依赖

- C++14 编译器
- CMake >= 3.10
- OpenCV >= 4.0

### Linux 编译

```bash
mkdir build && cd build
cmake ..
make -j$(nproc)
```

编译产物: `build/motion_detect`

## 使用方法

### 基本用法

```bash
./motion_detect [摄像头索引] [检测模式] [最小面积] [录制文件]
```

| 参数 | 默认值 | 说明 |
|------|--------|------|
| 摄像头索引 | 0 | 摄像头设备索引 |
| 检测模式 | 1 | 0=帧差法, 1=MOG2 |
| 最小面积 | 900 | 目标最小像素面积 |
| 录制文件 | (空) | 输出视频路径,不填则不录制 |

### 示例

```bash
# MOG2 模式 + 录制
./motion_detect 0 1 900 output.mp4

# 帧差法模式(轻量,适合嵌入式)
./motion_detect 0 0 500

# 查看帮助
./motion_detect --help
```

运行后按 `q` 键退出。

## 模块说明

| 模块 | 文件 | 功能 |
|------|------|------|
| FrameQueue | `frame_queue.h/cpp` | 线程安全帧队列,互斥锁 + 条件变量 |
| MotionDetector | `motion_detector.h/cpp` | 运动检测器,帧差法/MOG2 双模式 |
| VideoRecorder | `video_recorder.h/cpp` | 视频录制器,多编码格式 |
| Main | `main.cpp` | 主程序:采集线程 + 处理循环 + 显示 |

## 两种检测模式对比

| 特性 | 帧差法 | MOG2 |
|------|--------|------|
| 代码量 | 少(~20行核心) | 多(依赖 OpenCV 背景建模模块) |
| 计算量 | 低 | 较高 |
| 适用场景 | 嵌入式、资源受限设备 | PC、光照变化场景 |
| 光照变化 | 敏感 | 自适应 |
| 动态背景 | 不适应 | 适应(多高斯分布) |
| 初始化要求 | 首帧即背景 | 需要几帧学习背景 |

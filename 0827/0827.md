# opencv


## 图像,图形
图形:工具绘制
图像:设备采集并进行数字编码存储到计算机

- 位图:bmp 存储了各个像素的原始信息
  无损压缩
  - png:32位/24位(3通道 rgb) 4通道 alpha通道 透明 便于网络传输
- 有损压缩:
  - jpeg:24位 3通道 照片
  - gif:8位 256色 多帧合并
  - webp:压缩比例极低
  - ...

### Mat 类（图像容器）
- `Mat` 是 OpenCV 核心数据结构，存储图像/矩阵
- 常用构造：`Mat img = imread("xxx.png");` / `Mat gray(rows, cols, CV_8UC1);`
- 空 Mat 判断：`if (img.empty()) { /* 加载失败 */ }`
- 常用属性：`img.rows` 行数、`img.cols` 列数、`img.channels()` 通道数、`img.type()` 数据类型

### 颜色空间
- **BGR**：OpenCV 默认读取顺序（imread 读进来就是 BGR，不是 RGB）
- **GRAY**：灰度图，单通道 8 位
- **HSV**：色调(Hue)/饱和度(Saturation)/明度(Value)，常用于颜色追踪
- 转换：`cvtColor(src, dst, COLOR_BGR2GRAY);` / `COLOR_BGR2HSV;`

### VideoWriter 录制示例
```c++
// fourcc 编码器（avi 用 CV_FOURCC('M','J','P','G') 或 XVID）
VideoWriter writer("output.avi", CV_FOURCC('M','J','P','G'), 30, Size(640, 480));

Mat frame;
while (capture.read(frame))
{
    writer.write(frame);  // 写入一帧
    imshow("video", frame);
    if (waitKey(30) == 'q') break;
}
writer.release();  // 释放录制
```


## 视频处理

### 图像处理函数
```c++
// 均值滤波（模糊）
blur(src, dst, Size(5, 5));

// 高斯滤波（保留边缘细节）
GaussianBlur(src, dst, Size(3, 3), 0, 0);

// 双边滤波（保边去噪，慢）
bilateralFilter(src, dst, 9, 75, 75);

// 二值化（黑白分明）
cvtColor(src, gray, COLOR_BGR2GRAY);
threshold(gray, binary, 127, 255, THRESH_BINARY);

// 边缘检测
Canny(gray, edges, 50, 150);
```

### 形态学操作（膨胀/腐蚀）
```c++
Mat kernel = getStructuringElement(MORPH_RECT, Size(5, 5));
dilate(src, dst, kernel);   // 膨胀（白色区域扩大）
erode(src, dst, kernel);    // 腐蚀（白色区域缩小）
```

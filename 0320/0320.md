# 线性表（Linear List）

## 线性表的定义

**线性表**是一种最基本的数据结构，它是由n个数据元素组成的有限序列。其中：
- 除第一个元素外，每个元素都有唯一的前驱元素
- 除最后一个元素外，每个元素都有唯一的后继元素
- 元素之间存在一对一的线性关系

## 线性表的特点

1. **有限性**：线性表中的元素个数是有限的
2. **有序性**：元素之间存在明确的顺序关系
3. **同质性**：线性表中的元素具有相同的数据类型
4. **抽象性**：线性表是一种逻辑结构，不涉及具体的存储方式

## 线性表的分类

根据存储结构的不同，线性表可以分为：

### 1. 顺序表（Sequential List）

**定义**：使用顺序存储结构实现的线性表，通常用数组实现。

**特点**：
- 元素在内存中连续存储
- 通过下标直接访问元素，时间复杂度O(1)
- 插入和删除操作需要移动元素，时间复杂度O(n)
- 容量固定，需要预先分配空间

**C语言实现示例**：
```c
#define MAX_SIZE 100

typedef struct {
    int data[MAX_SIZE];  // 存储元素的数组
    int length;          // 当前元素个数
} SeqList;

// 初始化顺序表
void InitList(SeqList *L) {
    L->length = 0;
}

// 获取元素
int GetElem(SeqList L, int i, int *e) {
    if (i < 1 || i > L.length) return 0;
    *e = L.data[i - 1];
    return 1;
}

// 插入元素
int InsertList(SeqList *L, int i, int e) {
    if (i < 1 || i > L->length + 1 || L->length >= MAX_SIZE) return 0;
    for (int j = L->length; j >= i; j--) {
        L->data[j] = L->data[j - 1];
    }
    L->data[i - 1] = e;
    L->length++;
    return 1;
}

// 删除元素
int DeleteList(SeqList *L, int i, int *e) {
    if (i < 1 || i > L->length) return 0;
    *e = L->data[i - 1];
    for (int j = i; j < L->length; j++) {
        L->data[j - 1] = L->data[j];
    }
    L->length--;
    return 1;
}
```

### 2. 链表（Linked List）

**定义**：使用链式存储结构实现的线性表，通过指针将节点链接起来。

**特点**：
- 元素在内存中不连续存储
- 通过指针访问元素，时间复杂度O(n)
- 插入和删除操作只需要修改指针，时间复杂度O(1)
- 动态分配内存，不需要预先确定大小

**单链表C语言实现示例**：
```c
typedef struct Node {
    int data;           // 数据域
    struct Node *next;  // 指针域
} Node, *LinkList;

// 初始化链表
void InitList(LinkList *L) {
    *L = NULL;
}

// 创建链表（头插法）
void CreateList(LinkList *L, int n) {
    *L = (LinkList)malloc(sizeof(Node));
    (*L)->next = NULL;
    for (int i = n; i > 0; i--) {
        LinkList p = (LinkList)malloc(sizeof(Node));
        printf("请输入第%d个元素: ", i);
        scanf("%d", &p->data);
        p->next = (*L)->next;
        (*L)->next = p;
    }
}

// 获取元素
int GetElem(LinkList L, int i, int *e) {
    LinkList p = L->next;
    int j = 1;
    while (p && j < i) {
        p = p->next;
        j++;
    }
    if (!p || j > i) return 0;
    *e = p->data;
    return 1;
}

// 插入元素
int InsertList(LinkList L, int i, int e) {
    LinkList p = L;
    int j = 0;
    while (p && j < i - 1) {
        p = p->next;
        j++;
    }
    if (!p || j > i - 1) return 0;
    LinkList s = (LinkList)malloc(sizeof(Node));
    s->data = e;
    s->next = p->next;
    p->next = s;
    return 1;
}

// 删除元素
int DeleteList(LinkList L, int i, int *e) {
    LinkList p = L, q;
    int j = 0;
    while (p->next && j < i - 1) {
        p = p->next;
        j++;
    }
    if (!p->next || j > i - 1) return 0;
    q = p->next;
    p->next = q->next;
    *e = q->data;
    free(q);
    return 1;
}
```

## 线性表的基本操作

### 基本操作列表

1. **初始化**：创建一个空的线性表
2. **销毁**：释放线性表占用的内存
3. **清空**：删除线性表中的所有元素
4. **判空**：判断线性表是否为空
5. **长度**：获取线性表中的元素个数
6. **获取元素**：获取指定位置的元素
7. **查找元素**：查找元素在线性表中的位置
8. **插入元素**：在指定位置插入新元素
9. **删除元素**：删除指定位置的元素
10. **遍历**：依次访问线性表中的所有元素

## 顺序表与链表的比较

| 特性 | 顺序表 | 链表 |
|------|--------|------|
| **存储方式** | 连续存储 | 分散存储 |
| **访问方式** | 随机访问（O(1)） | 顺序访问（O(n)） |
| **插入操作** | 需要移动元素（O(n)） | 只需修改指针（O(1)） |
| **删除操作** | 需要移动元素（O(n)） | 只需修改指针（O(1)） |
| **空间利用率** | 可能存在浪费 | 每个节点有指针开销 |
| **扩容** | 需要重新分配内存 | 动态分配，无需扩容 |
| **适用场景** | 频繁访问，较少插入删除 | 频繁插入删除，较少访问 |

## 时间复杂度分析

### 顺序表操作时间复杂度

| 操作 | 时间复杂度 |
|------|------------|
| 获取元素 | O(1) |
| 查找元素 | O(n) |
| 插入元素 | O(n) |
| 删除元素 | O(n) |
| 遍历 | O(n) |

### 链表操作时间复杂度

| 操作 | 时间复杂度 |
|------|------------|
| 获取元素 | O(n) |
| 查找元素 | O(n) |
| 插入元素 | O(1)（已知位置） |
| 删除元素 | O(1)（已知位置） |
| 遍历 | O(n) |

## 线性表的应用

1. **数组**：最常见的顺序表实现
2. **栈**：受限的线性表（后进先出）
3. **队列**：受限的线性表（先进先出）
4. **字符串**：字符的线性表
5. **多项式表示**：使用链表表示多项式
6. **稀疏矩阵**：使用链表存储稀疏矩阵

## 总结

线性表是数据结构中最基础、最重要的数据结构之一。理解线性表的概念、特点和操作是学习其他复杂数据结构的基础。在实际应用中，需要根据具体的需求选择合适的线性表实现方式（顺序表或链表）。

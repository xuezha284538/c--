## 〇、算法背景

### 0.1 KMP算法的历史

KMP算法是由三位计算机科学家独立发现并发表的：

| 科学家 | 国籍 | 贡献 |
|--------|------|------|
| **Donald Knuth** | 美国 | 著名计算机科学家，《计算机程序设计艺术》作者 |
| **James H. Morris** | 美国 | 卡内基梅隆大学教授 |
| **Vaughan Pratt** | 美国 | 斯坦福大学教授 |

**发表时间**：1977年

**历史意义**：
- 这是第一个线性时间复杂度的字符串匹配算法
- 开创了利用模式串自身特性优化匹配的先河
- 成为算法课程中的经典教学内容

### 0.2 算法命名由来

```
KMP = Knuth-Morris-Pratt
      ↓      ↓      ↓
   三位发明者的姓氏首字母
```

### 0.3 为什么需要KMP算法？

#### 暴力匹配的问题

```
主串:   A B A B A B C
模式串: A B C

暴力匹配过程：
位置0: A B A B A B C  ← 匹配到第3个字符失败
       A B C
       ↑ ↑ ✗
       
位置1: A B A B A B C  ← 主串指针回退到位置1
         A B C
         ↑ ✗
         
位置2: A B A B A B C  ← 主串指针回退到位置2
           A B C
           ↑ ✗
           
...以此类推

问题：主串指针频繁回退，效率低下！
```

#### KMP的解决方案

```
核心思想：当匹配失败时，利用已经匹配过的信息，
         避免主串指针回退，只调整模式串指针。

主串:   A B A B A B C
模式串: A B C

KMP匹配过程：
位置0: A B A B A B C  ← 匹配到第3个字符失败
       A B C
       ↑ ↑ ✗
       
       利用next数组，模式串右移，主串指针不回退！
       
位置2: A B A B A B C  ← 主串指针保持在位置2
           A B C
           ↑ ✗
           
优势：主串指针永远不回退！时间复杂度 O(n+m)
```

### 0.4 KMP算法的核心概念

#### 最长公共前后缀

```
定义：一个字符串的最长公共前后缀，是指该字符串中
     最长的、相等的、前缀和后缀。

示例：
字符串 "ABA"
  前缀: A, AB
  后缀: A, BA
  公共前后缀: A
  最长公共前后缀: "A"，长度=1

字符串 "ABAB"
  前缀: A, AB, ABA
  后缀: B, AB, BAB
  公共前后缀: AB
  最长公共前后缀: "AB"，长度=2

字符串 "ABC"
  前缀: A, AB
  后缀: C, BC
  公共前后缀: 无
  最长公共前后缀: ""，长度=0
```

#### next数组的含义

```
next[i] = 模式串前i个字符的最长公共前后缀长度

示例：模式串 "ABABC"
位置  字符串   最长公共前后缀  next值
0     A        无             -1（边界）
1     AB       无             0
2     ABA      "A"            1
3     ABAB     "AB"           2
4     ABABC    无             0
```

### 0.5 KMP算法的应用领域

| 领域 | 应用场景 |
|------|----------|
| **文本编辑器** | 查找、替换、高亮显示 |
| **搜索引擎** | 关键词匹配、文档检索 |
| **生物信息学** | DNA/RNA序列匹配、基因比对 |
| **网络安全** | 入侵检测、特征码匹配 |
| **编译器** | 词法分析、关键字识别 |
| **数据压缩** | LZ77等算法中的字符串查找 |
| **拼写检查** | 单词匹配、相似度计算 |

### 0.6 KMP算法的优缺点

| 优点 | 缺点 |
|------|------|
| 时间复杂度 O(n+m)，高效 | 需要额外 O(m) 空间存储next数组 |
| 主串指针不回退，适合流式数据 | 实现相对复杂 |
| 对于长模式串优势明显 | 对于短模式串，优势不明显 |
| 理论价值高，是经典算法 | 实际应用中，BM算法可能更快 |

## 三、核心算法设计

### 3.1 暴力匹配算法（Brute Force）

#### 算法思想

从主串的每个位置开始，依次与模式串进行比较：

```
主串: ABCABCD
模式串: ABC

位置0: ABCABCD  ✓✓✓ 匹配成功
位置1: ABCABCD  ✓✗✗ 匹配失败
位置2: ABCABCD  ✓✗✗ 匹配失败
```

#### 代码实现

```c
int bf(char* a, char* s, int a_len, int s_len)
{
    int i, j, k;

    for (i = 0; i <= a_len - s_len; i++) {
        k = i;
        for (j = 0; j < s_len; j++) {
            if (a[k] == s[j]) {
                k++;
            } else {
                break;
            }
        }
        if (j == s_len) {
            return i;
        }
    }
    return -1;
}
```

#### 复杂度分析

| 复杂度 | 值 | 说明 |
|--------|-----|------|
| 时间复杂度 | O(n×m) | 最坏情况下需比较n-m+1次，每次最多比较m次 |
| 空间复杂度 | O(1) | 仅使用常数个变量 |

### 3.2 KMP匹配算法

#### 算法思想

KMP（Knuth-Morris-Pratt）算法的核心思想是：**当匹配失败时，利用已匹配的信息，避免不必要的回溯**。

#### 最长公共前后缀

```c
// 示例分析模式串 "ABABC"
位置0: A        → next[0] = -1
位置1: AB       → 最长公共前后缀: "" → next[1] = 0
位置2: ABA      → 最长公共前后缀: "A" → next[2] = 1
位置3: ABAB     → 最长公共前后缀: "AB" → next[3] = 2
位置4: ABABC    → 最长公共前后缀: "" → next[4] = 0
```

#### next数组构建算法

```c
void next1(int a[], char b[], int len)
{
    a[0] = -1;
    int j = 0, k = -1;//j是后缀的终点,k是前缀的终点也是最大公共前后缀长度

    while (j < len) {
        if (k == -1 || b[k] == b[j]) {
            j++;
            k++;
            a[j] = k;
        } else {
            k = a[k];
        }
    }
}
```

**算法原理**：

| 变量 | 含义 |
|------|------|
| `j` | 当前计算的位置（后缀终点） |
| `k` | 当前最长公共前后缀长度（前缀终点） |
| `a[k]` | 回溯位置（当字符不匹配时） |

##### 回溯机制详解

```
为什么 j = a[j] 能找到正确的回溯位置？

┌─────────────────────────────────────────────────────────────┐
│ 场景：计算 next[4] 时，b[2]='A' != b[4]='C' 发生不匹配       │
├─────────────────────────────────────────────────────────────┤
│ 已知信息：                                                   │
│   前4个字符 "ABAB" 的最长公共前后缀是 "AB"，长度=2           │
│   即 next[3] = 2                                            │
├─────────────────────────────────────────────────────────────┤
│ 回溯过程：                                                   │
│   步骤1: j = a[2] = 0                                       │
│          尝试更短的公共前后缀 "A"，比较 b[0]='A' 和 b[4]='C' │
│          不匹配                                              │
│                                                             │
│   步骤2: j = a[0] = -1                                      │
│          没有更短的公共前后缀，重新开始                         │
│                                                             │
│   步骤3: j == -1 触发，i++→5, j++→0, a[5]=0                │
└─────────────────────────────────────────────────────────────┘

图示：
模式串:  A   B   A   B   C
索引:     0   1   2   3   4
          ├───┘
          j=2, k=2 → b[2]='A' != b[4]='C' → 回溯
          │
          j = a[2] = 0
          │
          b[0]='A' != b[4]='C' → 继续回溯
          │
          j = a[0] = -1
          │
          重新开始
```

#### KMP匹配算法

```c
int kmp(char* a, char* s, int* next, int s_len, int a_len)
{
    int i = 0, j = 0;

    while (i < a_len && j < s_len) {
        if (j == -1 || a[i] == s[j]) {
            i++;
            j++;
        } else {
            j = next[j];
        }
    }

    if (j == s_len) {
        return i - j;  // 匹配成功，返回起始位置
    } else {
        return -1;     // 匹配失败
    }
}
```

```
      └──────────────────────┘
            (继续循环)
```

##### KMP匹配详细示例（主串 "ABABABC"，模式串 "ABC"）

```
┌────────────────────────────────────────────────────────────────┐
│ 初始状态                                                       │
│   主串: A B A B A B C                                          │
│   模式: A B C                                                  │
│   i=0, j=0                                                    │
│   next = [-1, 0, 0]                                           │
├────────────────────────────────────────────────────────────────┤
│ 步骤1: i=0, j=0                                               │
│   a[0]='A' == s[0]='A'? 是                                   │
│   执行: i++→1, j++→1                                          │
│   继续匹配下一个字符                                            │
├────────────────────────────────────────────────────────────────┤
│ 步骤2: i=1, j=1                                               │
│   a[1]='B' == s[1]='B'? 是                                   │
│   执行: i++→2, j++→2                                          │
│   继续匹配下一个字符                                            │
├────────────────────────────────────────────────────────────────┤
│ 步骤3: i=2, j=2                                               │
│   a[2]='A' == s[2]='C'? 否                                   │
│   执行: j = next[2] = 0                                       │
│   回溯到模式串位置0继续比较                                     │
├────────────────────────────────────────────────────────────────┤
│ 步骤4: i=2, j=0                                               │
│   a[2]='A' == s[0]='A'? 是                                   │
│   执行: i++→3, j++→1                                          │
│   继续匹配下一个字符                                            │
├────────────────────────────────────────────────────────────────┤
│ 步骤5-7: 继续匹配                                              │
│   a[3]='B'==s[1]='B'? 是 → i=4, j=2                         │
│   a[4]='A'==s[2]='C'? 否 → j=next[2]=0                      │
│   a[4]='A'==s[0]='A'? 是 → i=5, j=1                         │
│   a[5]='B'==s[1]='B'? 是 → i=6, j=2                         │
│   a[6]='C'==s[2]='C'? 是 → i=7, j=3                         │
├────────────────────────────────────────────────────────────────┤
│ 步骤8: i=7, j=3                                               │
│   j == s_len(3)? 是                                           │
│   返回: i - j = 7 - 3 = 4                                     │
│   匹配成功！位置4                                              │
└────────────────────────────────────────────────────────────────┘




```

#### 从指定位置继续匹配

```c
int kmp_from(char* a, char* s, int* next, int s_len, int a_len, int start)
{
    int i = start, j = 0;

    while (i < a_len && j < s_len) {
        if (j == -1 || a[i] == s[j]) {
            i++;
            j++;
        } else {
            j = next[j];
        }
    }

    if (j == s_len) {
        return i - j;
    } else {
        return -1;
    }
}
```

### 3.3 多次匹配算法

#### 允许重叠的多次匹配

```c
// 模式2：多次重复匹配（允许重叠）
// 示例："ppp" 查找 "pp" → 位置0, 位置1
pos = kmp(a, s, next, s_len, a_len);
while (pos != -1) {
    printf("位置 %d\n", pos);
    pos = kmp_from(a, s, next, s_len, a_len, pos + 1);  // 从pos+1继续
}
```

**原理**：每次匹配成功后，从**当前位置+1**继续查找，允许匹配位置重叠。

#### 不允许重叠的多次匹配

```c
// 模式3：多次不重复匹配（不允许重叠）
// 示例："ppp" 查找 "pp" → 位置0
pos = kmp(a, s, next, s_len, a_len);
while (pos != -1) {
    printf("位置 %d\n", pos);
    pos = kmp_from(a, s, next, s_len, a_len, pos + s_len);  // 从pos+模式长度继续
}
```

**原理**：每次匹配成功后，从**当前位置+模式串长度**继续查找，确保匹配不重叠。

## 五、难点与解决方法

### 5.1 next数组构建的难点

#### 难点1：回溯位置的理解

**问题**：为什么 `j = a[j]` 可以找到正确的回溯位置？

**分析**：
```
模式串: ABABC
next数组: -1,0,1,2,0

当j=4, k=2时发生不匹配：
b[4]=C, b[2]=A，不匹配

k = a[k] = a[2] = 1
此时比较 b[4]=C, b[1]=B，不匹配

k = a[k] = a[1] = 0
此时比较 b[4]=C, b[0]=A，不匹配

k = a[k] = a[0] = -1
j++, k++，继续匹配
```

**结论**：`a[j]` 存储的正是当前前缀的"最长公共前后缀长度对应的下一个位置"。


### 5.2 KMP匹配失败时的处理

#### 问题分析

当匹配失败时，模式串不需要回溯到开头，而是利用next数组跳转到合适的位置继续匹配。

#### 解决方案

```c
if (j == -1 || a[i] == s[j]) {
    i++;
    j++;
} else {
    j = next[j];  // 利用next数组跳转
}
```

**关键点**：
- `j == -1`：表示模式串第一个字符就不匹配，需要从主串的下一个位置重新开始
- `next[j]`：模式串前j个字符的最长公共前后缀长度，用于确定下一个比较位置

```c
        if (len > 0)
```

```c
/**
 * @brief 暴力匹配算法（Brute Force）
 */
int bf(char *a, char *s, int a_len, int s_len)
{
    int i, j, k;

    for (i = 0; i <= a_len - s_len; i++)
    {
        k = i;
        for (j = 0; j < s_len; j++)
        {
            if (a[k] == s[j])
            {
                k++;
            }
            else
            {
                break;
            }
        }
        if (j == s_len)
        {
            return i;
        }
    }
    return -1;
}
```

```c
#include "kmp.h"

/**
 * @brief 构建KMP算法的next数组
 */
void next1(int a[], char b[], int len)
{
    a[0] = -1;
    int i = 0, j = -1;
    while (i < len)
    {
        if (j == -1 || b[j] == b[i])
        {
            i++;
            j++;
            a[i] = j;
        }
        else
        {
            j = a[j];
        }
    }
}

/**
 * @brief KMP字符串匹配算法
 */
int kmp(char *a, char *s, int *next, int s_len, int a_len)
{
    return kmp_from(a, s, next, s_len, a_len, 0);
}

/**
 * @brief 从指定位置开始的KMP字符串匹配算法
 */
int kmp_from(char *a, char *s, int *next, int s_len, int a_len, int start)
{
    int i = start, j = 0;

    while (i < a_len && j < s_len)
    {
        if (j == -1 || a[i] == s[j])
        {
            i++;
            j++;
        }
        else
        {
            j = next[j];
        }
    }

    if (j == s_len)
    {
        return i - j;
    }
    else
    {
        return -1;
    }
}
```

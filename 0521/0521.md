# io -File 操作

## 文件概念

UNIX  `一切皆文件`
### 狭义上的文件
 - 文件 
 - 文件夹/目录

### 广义 ls-l 
- 文件      - 普通文件 文本 二进制文件
- 目录      d
- 链接      l
- 块设备    block
- 字符设备  char
- 管道      p
- 套接字    s

### 流 stream
数据(字节)构成的序列

- 输入流 std in  读取 接收

- 输出流 std  out 发送 写


## c api C API

FILE
- `fopen`       打开文件
- `fclose`      关闭文件
- `fgetc`       char   读取 文本
- `fputc`       char   写入 文本
- `fgets`       string 读取 文本
- `fputs`       string 写入 文本
- `fread`       二进制: 程序 图像 word excel... 也能读取字符
- `fwrite`      二进制: 程序 图像 word excel... 也能写入字符
- `fseek`       随机访问 
- `ftell`       获得 当前距离文件开头有多少个字节
- `rewind`      回到 文件开头位置
- `fprintf`
- `...`

# 网络编程

## 网络
通过有线无线的介质链接计算机设备 进行数据通信或者设备控制
介质
- 有线: 网线 光纤 双绞线(150m) 同轴电缆
- 无线: 蓝牙 wifi zigbee 移动网络 卫星 

网路设备
- 计算机 终端
- 手机
- 平板
- 交换机 switcher  组成一个局域网络
- 路由器 router  网络与网络的链接 与互联网
- 集线器: hub

网络拓扑:连接的设备的几何结构 计算机设备与网络链路构成的几何结构
- 星形 局域网 计算机+交换机+集线器
- 环形
- 树形
- 总线

核心
- 数据通信
- 设备控制

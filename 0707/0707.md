# 套接字编程 -udp


## tcp & udp
| 特征     | tcp    | udp               |
| -------- | ------ | ----------------- |
| 建立连接 | 是     | 否                |
| 可靠     | 是     | 否                |
| 有序     | 是     | 否                |
| 丢包     | 重发   | 忽略              |
| 数据大小 | 不受限 | 65535,mtu=1500-28 |

应用场景
- tcp :ftp http 数据可靠传输
- udp :视频 游戏 传感器

tcp开发流程

- listen
- accept
- write/read
- close

客户端
- connect -accept
- write
- read

## UDP

- sendto(data ,addr,...)
- close

recv 接收
- socket
- bind
- recvform

# 网络 套接字编程 - tcp
## 套接字socket
套接字是tcp/ip 实现中出现的概率 封装网络底层通信细节操作方式类似文件

### ip
接入网络的计算机的逻辑标识 动态分配给计算机的一个标识信息
mac地址 :6个字节 物理标识 硬件设备的标识 出场时设定的 也是唯一标识
ipv4 :2^32=42亿
ipv6 :2^128=340亿亿

### port端口号
一台计算机有唯一的ip标识 但是同时运行上百行的进程,端口号 标识收/发数据的进程 ;
端口号也是虚拟的 2^16 65536 2字节 :前1014保留 
### tcp 套接字的流程 api
服务器端
- socket() 创建套接字的文件描述符 返回整形指针
- bind() 绑定地址
- listen() 开启监听,初始化一个队列 接收客户端的请求
- accept()接收请求 
- read()/write()读写数据
- close()关闭套接字

### 大小端
- `htons()` host to net short
- `htonl()` host to net long
- `ntohs()` net to host short
- `ntohl()` net to host long

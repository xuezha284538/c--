# 查找与排序算法

---

## 一、查找算法

### 1. 顺序查找（线性查找）

**核心思想**：从第一个元素开始，逐个检查直到找到目标元素。

**时间复杂度**：
- 最好：O(1)
- 最坏：O(n)
- 平均：O(n)

**适用场景**：无序数组、链表

**代码实现**：
```c
int sequential_search(int arr[], int n, int target) {
    for (int i = 0; i < n; i++) {
        if (arr[i] == target) {
            return i;  // 找到返回索引
        }
    }
    return -1;  // 未找到
}
```

---

### 2. 折半查找（二分查找）

**核心思想**：每次将搜索范围缩小一半，适用于有序数组。

**时间复杂度**：
- 最好：O(1)
- 最坏：O(log n)
- 平均：O(log n)

**适用场景**：有序数组、静态查找表

**代码实现**：
```c
int binary_search(int arr[], int n, int target) {
    int left = 0, right = n - 1;
    while (left <= right) {
        int mid = left + (right - left) / 2;  // 避免溢出
        if (arr[mid] == target) {
            return mid;
        } else if (arr[mid] < target) {
            left = mid + 1;
        } else {
            right = mid - 1;
        }
    }
    return -1;
}
```

---

### 3. 分块查找（索引顺序查找）

**核心思想**：将数组分成若干块，先在索引表中找到块，再在块内顺序查找。

**时间复杂度**：O(√n)

**适用场景**：大规模数据、需要兼顾顺序查找和二分查找

**结构**：
```
索引表：[块最大元素, 块起始位置]
数据块：每个块内无序，块间有序
```

## 二、排序算法

### 1. 基于插入的排序

#### 1.1 直接插入排序

**核心思想**：将元素插入到已排序部分的正确位置。

**时间复杂度**：
- 最好：O(n)（已排序）
- 最坏：O(n²)（逆序）
- 平均：O(n²)

**空间复杂度**：O(1)

**稳定性**：稳定

**代码实现**：
```c
void insertion_sort(int arr[], int n) {
    for (int i = 1; i < n; i++) {
        int key = arr[i];
        int j = i - 1;
        while (j >= 0 && arr[j] > key) {
            arr[j + 1] = arr[j];
            j--;
        }
        arr[j + 1] = key;
    }
}
```

#### 1.2 折半插入排序

**核心思想**：用二分查找确定插入位置，减少比较次数。

**时间复杂度**：O(n²)（移动次数不变）

**适用场景**：数据量不大的有序数组

#### 1.3 希尔排序（Shell Sort）

**核心思想**：将数组分成多个子序列分别插入排序，逐步缩小增量。

**时间复杂度**：O(n log n) ~ O(n²)，取决于增量序列

**空间复杂度**：O(1)

**稳定性**：不稳定

**代码实现**：
```c
void shell_sort(int arr[], int n) {
    for (int gap = n / 2; gap > 0; gap /= 2) {
        for (int i = gap; i < n; i++) {
            int key = arr[i];
            int j = i;
            while (j >= gap && arr[j - gap] > key) {
                arr[j] = arr[j - gap];
                j -= gap;
            }
            arr[j] = key;
        }
    }
}
```

### 2. 基于交换的排序

#### 2.1 冒泡排序

**核心思想**：重复遍历数组，交换相邻逆序元素。

**时间复杂度**：
- 最好：O(n)（已排序，加标志优化）
- 最坏：O(n²)
- 平均：O(n²)

**空间复杂度**：O(1)

**稳定性**：稳定

**代码实现**：
```c
void bubble_sort(int arr[], int n) {
    for (int i = 0; i < n - 1; i++) {
        int swapped = 0;
        for (int j = 0; j < n - 1 - i; j++) {
            if (arr[j] > arr[j + 1]) {
                int temp = arr[j];
                arr[j] = arr[j + 1];
                arr[j + 1] = temp;
                swapped = 1;
            }
        }
        if (!swapped) break;  // 无交换说明已有序
    }
}
```

#### 2.2 快速排序

**核心思想**：选择基准元素，将数组分成两部分，递归排序。

**时间复杂度**：
- 最好：O(n log n)
- 最坏：O(n²)（已排序数组，选择首尾作为基准）
- 平均：O(n log n)

**空间复杂度**：O(log n) ~ O(n)

**稳定性**：不稳定

**示例**：
```
初始数组：10 15 14 18 20 40 36 21
基准选择：第一个元素 10

第一轮划分：
小于10：无
大于等于10：15, 14, 18, 20, 40, 36, 21

递归排序左右部分...
```

**代码实现**：
```c
int partition(int arr[], int low, int high) {
    int pivot = arr[low];
    while (low < high) {
        while (low < high && arr[high] >= pivot) high--;
        arr[low] = arr[high];
        while (low < high && arr[low] <= pivot) low++;
        arr[high] = arr[low];
    }
    arr[low] = pivot;
    return low;
}

void quick_sort(int arr[], int low, int high) {
    if (low < high) {
        int pos = partition(arr, low, high);
        quick_sort(arr, low, pos - 1);
        quick_sort(arr, pos + 1, high);
    }
}
```

### 3. 基于选择的排序

#### 3.1 简单选择排序

**核心思想**：每次选择最小元素放到已排序部分末尾。

**时间复杂度**：O(n²)（最好、最坏、平均）

**空间复杂度**：O(1)

**稳定性**：不稳定

**代码实现**：
```c
void selection_sort(int arr[], int n) {
    for (int i = 0; i < n - 1; i++) {
        int min_idx = i;
        for (int j = i + 1; j < n; j++) {
            if (arr[j] < arr[min_idx]) {
                min_idx = j;
            }
        }
        if (min_idx != i) {
            int temp = arr[i];
            arr[i] = arr[min_idx];
            arr[min_idx] = temp;
        }
    }
}
```

#### 3.2 堆排序

**核心思想**：利用堆数据结构，每次取出堆顶元素。

**时间复杂度**：
- 最好：O(n log n)
- 最坏：O(n log n)
- 平均：O(n log n)

**空间复杂度**：O(1)

**稳定性**：不稳定

**代码实现**：
```c
void heapify(int arr[], int n, int i) {
    int largest = i;
    int left = 2 * i + 1;
    int right = 2 * i + 2;
    
    if (left < n && arr[left] > arr[largest]) largest = left;
    if (right < n && arr[right] > arr[largest]) largest = right;
    
    if (largest != i) {
        int temp = arr[i];
        arr[i] = arr[largest];
        arr[largest] = temp;
        heapify(arr, n, largest);
    }
}

void heap_sort(int arr[], int n) {
    for (int i = n / 2 - 1; i >= 0; i--) heapify(arr, n, i);
    for (int i = n - 1; i > 0; i--) {
        int temp = arr[0];
        arr[0] = arr[i];
        arr[i] = temp;
        heapify(arr, i, 0);
    }
}
```

### 4. 归并排序

**核心思想**：分治策略，将数组分成两半分别排序，然后合并。

**时间复杂度**：
- 最好：O(n log n)
- 最坏：O(n log n)
- 平均：O(n log n)

**空间复杂度**：O(n)

**稳定性**：稳定

**代码实现**：
```c
void merge(int arr[], int left, int mid, int right) {
    int n1 = mid - left + 1;
    int n2 = right - mid;
    int L[n1], R[n2];
    
    for (int i = 0; i < n1; i++) L[i] = arr[left + i];
    for (int j = 0; j < n2; j++) R[j] = arr[mid + 1 + j];
    
    int i = 0, j = 0, k = left;
    while (i < n1 && j < n2) {
        if (L[i] <= R[j]) arr[k++] = L[i++];
        else arr[k++] = R[j++];
    }
    
    while (i < n1) arr[k++] = L[i++];
    while (j < n2) arr[k++] = R[j++];
}

void merge_sort(int arr[], int left, int right) {
    if (left < right) {
        int mid = left + (right - left) / 2;
        merge_sort(arr, left, mid);
        merge_sort(arr, mid + 1, right);
        merge(arr, left, mid, right);
    }
}
```

### 5. 基数排序

**核心思想**：按数字的每一位进行排序，从低位到高位。

**时间复杂度**：O(d × (n + r))
- d：数字位数
- r：基数（进制）

**空间复杂度**：O(n + r)

**稳定性**：稳定

**代码实现**：
```c
void radix_sort(int arr[], int n) {
    int max = arr[0];
    for (int i = 1; i < n; i++) {
        if (arr[i] > max) max = arr[i];
    }
    
    for (int exp = 1; max / exp > 0; exp *= 10) {
        int output[n];
        int count[10] = {0};
        
        for (int i = 0; i < n; i++) count[(arr[i] / exp) % 10]++;
        for (int i = 1; i < 10; i++) count[i] += count[i - 1];
        
        for (int i = n - 1; i >= 0; i--) {
            output[count[(arr[i] / exp) % 10] - 1] = arr[i];
            count[(arr[i] / exp) % 10]--;
        }
        
        for (int i = 0; i < n; i++) arr[i] = output[i];
    }
}
```

## 三、排序算法对比

| 算法 | 最好时间 | 最坏时间 | 平均时间 | 空间复杂度 | 稳定性 |
|------|---------|---------|---------|-----------|--------|
| 直接插入 | O(n) | O(n²) | O(n²) | O(1) | 稳定 |
| 折半插入 | O(n) | O(n²) | O(n²) | O(1) | 稳定 |
| 希尔排序 | O(n log n) | O(n²) | O(n log n)~O(n²) | O(1) | 不稳定 |
| 冒泡排序 | O(n) | O(n²) | O(n²) | O(1) | 稳定 |
| 快速排序 | O(n log n) | O(n²) | O(n log n) | O(log n)~O(n) | 不稳定 |
| 简单选择 | O(n²) | O(n²) | O(n²) | O(1) | 不稳定 |
| 堆排序 | O(n log n) | O(n log n) | O(n log n) | O(1) | 不稳定 |
| 归并排序 | O(n log n) | O(n log n) | O(n log n) | O(n) | 稳定 |
| 基数排序 | O(d×(n+r)) | O(d×(n+r)) | O(d×(n+r)) | O(n+r) | 稳定 |

## 四、算法选择建议

| 场景 | 推荐算法 |
|------|---------|
| 数据量小（n < 100） | 直接插入、简单选择 |
| 数据基本有序 | 直接插入、冒泡排序 |
| 数据量大且需要稳定排序 | 归并排序 |
| 数据量大且注重空间 | 堆排序 |
| 通用场景 | 快速排序 |
| 整数/字符串排序 | 基数排序 |

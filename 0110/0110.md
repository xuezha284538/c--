## 结构体

```c
    // 封装，自定义的类型
    struct Student
    {
        // 姓名
        char name[16];  // 1
        // 成绩 
        int score;      // 2
        // 性别
        char sex;       // 3
    };

    int i = 2;
    int a[4] = {1,2,3,4};
    struct Student s1 = {"bob", 89, 'M'};
    struct Student s2 = {.sex='F', .score=100, .name="alice"};

    // 空间已经分配
    struct Stdunet s3;
    s3.score = 99;
    s3.sex = 'F';
    // s3.name = "king";    错了
    strcpy(s3.name, "king");
```

## 结构体的大小

内存对齐
- 最大类型长度的整数倍, 1,2,4,8
- 从小到大
- 避免大小交叉存储

## 共用体/联合体 union

内存分布方式不同，内存叠加

```c
    union U
    {
        char code;      // A,B,X
        float value;    // 3.2211313
    };
```

## 关系建模
表存储
- 实体或者概念或属性,表由多个列(字段),由多行(记录)构成
- 实体与实体之间的关系

关系建模 - 关系代数

关系范式
- 1NF:表的列是原子性的 不能是多个值 (也就是集合)
- 2NF:所有字段依赖于主键字段 创建复合主键
- 3NF:非键字段不依赖于任何非键字段 只依赖于主键


```sql
/*pk 主键约束*/
create table t5
(
    id int auto_increment primary key,
    name varchar(16),
    gender enum('男','女') default '男',
    birthday date,
    tel char(11),
    mother int /*FK 外键字段 是另一张表(另一个记录)的主键值*/

);


```

## 一、需求分析（业务场景分析）

### 1.1 项目背景

字符串匹配是计算机科学中最基本且重要的操作之一，广泛应用于：

- **文本编辑器**：查找、替换功能
- **搜索引擎**：关键词匹配、文档检索
- **生物信息学**：DNA序列匹配
- **网络入侵检测**：特征码匹配
- **编译器**：词法分析、关键字识别

### 1.2 功能需求

本项目实现一个完整的字符串匹配工具，支持：

| 功能 | 说明 |
|------|------|
| **单次匹配** | 查找模式串首次出现的位置 |
| **多次重复匹配** | 查找所有匹配位置（允许重叠） |
| **多次不重复匹配** | 查找所有匹配位置（不允许重叠） |
| **next数组生成** | 计算KMP算法所需的next数组 |
| **交互式菜单** | 支持用户通过菜单选择不同功能 |

### 1.3 性能需求

- 时间复杂度：O(n + m)，其中n为主串长度，m为模式串长度
- 空间复杂度：O(m) 用于存储next数组

## 三、核心算法设计

### 3.1 暴力匹配算法（Brute Force）

#### 算法思想

从主串的每个位置开始，依次与模式串进行比较：

```
主串: ABCABCD
模式串: ABC

位置0: ABCABCD  ✓✓✓ 匹配成功
位置1: ABCABCD  ✓✗✗ 匹配失败
位置2: ABCABCD  ✓✗✗ 匹配失败
```

#### 代码实现

```c
int bf(char* a, char* s, int a_len, int s_len)
{
    int i, j, k;

    for (i = 0; i <= a_len - s_len; i++) {
        k = i;
        for (j = 0; j < s_len; j++) {
            if (a[k] == s[j]) {
                k++;
            } else {
                break;
            }
        }
        if (j == s_len) {
            return i;
        }
    }
    return -1;
}
```

#### 复杂度分析

| 复杂度 | 值 | 说明 |
|--------|-----|------|
| 时间复杂度 | O(n×m) | 最坏情况下需比较n-m+1次，每次最多比较m次 |
| 空间复杂度 | O(1) | 仅使用常数个变量 |

### 3.2 KMP匹配算法

#### 算法思想

KMP（Knuth-Morris-Pratt）算法的核心思想是：**当匹配失败时，利用已匹配的信息，避免不必要的回溯**。

#### 最长公共前后缀

```c
// 示例分析模式串 "ABABC"
位置0: A        → next[0] = -1
位置1: AB       → 最长公共前后缀: "" → next[1] = 0
位置2: ABA      → 最长公共前后缀: "A" → next[2] = 1
位置3: ABAB     → 最长公共前后缀: "AB" → next[3] = 2
位置4: ABABC    → 最长公共前后缀: "" → next[4] = 0
```

#### next数组构建算法

```c
void next1(int a[], char b[], int len)
{
    a[0] = -1;
    int j = 0, k = -1;

    while (j < len) {
        if (k == -1 || b[k] == b[j]) {
            j++;
            k++;
            a[j] = k;
        } else {
            k = a[k];
        }
    }
}
```

**算法原理**：

| 变量 | 含义 |
|------|------|
| `j` | 当前计算的位置（后缀终点） |
| `k` | 当前最长公共前后缀长度（前缀终点） |
| `a[k]` | 回溯位置（当字符不匹配时） |

#### KMP匹配算法

```c
int kmp(char* a, char* s, int* next, int s_len, int a_len)
{
    int i = 0, j = 0;

    while (i < a_len && j < s_len) {
        if (j == -1 || a[i] == s[j]) {
            i++;
            j++;
        } else {
            j = next[j];
        }
    }

    if (j == s_len) {
        return i - j;  // 匹配成功，返回起始位置
    } else {
        return -1;     // 匹配失败
    }
}
```

### 3.3 多次匹配算法

#### 允许重叠的多次匹配

```c
// 模式2：多次重复匹配（允许重叠）
// 示例："ppp" 查找 "pp" → 位置0, 位置1
pos = kmp(a, s, next, s_len, a_len);
while (pos != -1) {
    printf("位置 %d\n", pos);
    pos = kmp_from(a, s, next, s_len, a_len, pos + 1);  // 从pos+1继续
}
```

**原理**：每次匹配成功后，从**当前位置+1**继续查找，允许匹配位置重叠。

#### 不允许重叠的多次匹配

```c
// 模式3：多次不重复匹配（不允许重叠）
// 示例："ppp" 查找 "pp" → 位置0
pos = kmp(a, s, next, s_len, a_len);
while (pos != -1) {
    printf("位置 %d\n", pos);
    pos = kmp_from(a, s, next, s_len, a_len, pos + s_len);  // 从pos+模式长度继续
}
```

**原理**：每次匹配成功后，从**当前位置+模式串长度**继续查找，确保匹配不重叠。

## 五、难点与解决方法

### 5.1 next数组构建的难点

#### 难点1：回溯位置的理解

**问题**：为什么 `j = a[j]` 可以找到正确的回溯位置？

**分析**：
```
模式串: ABABC
next数组: -1,0,1,2,0

当j=4, k=2时发生不匹配：
b[4]=C, b[2]=A，不匹配

k = a[k] = a[2] = 1
此时比较 b[4]=C, b[1]=B，不匹配

k = a[k] = a[1] = 0
此时比较 b[4]=C, b[0]=A，不匹配

k = a[k] = a[0] = -1
j++, k++，继续匹配
```

**结论**：`a[j]` 存储的正是当前前缀的"最长公共前后缀长度对应的下一个位置"。


### 5.2 KMP匹配失败时的处理

#### 问题分析

当匹配失败时，模式串不需要回溯到开头，而是利用next数组跳转到合适的位置继续匹配。

#### 解决方案

```c
if (j == -1 || a[i] == s[j]) {
    i++;
    j++;
} else {
    j = next[j];  // 利用next数组跳转
}
```

**关键点**：
- `j == -1`：表示模式串第一个字符就不匹配，需要从主串的下一个位置重新开始
- `next[j]`：模式串前j个字符的最长公共前后缀长度，用于确定下一个比较位置

### 6.3 KMP vs 暴力匹配对比

| 特性 | 暴力匹配(BF) | KMP |
|------|-------------|-----|
| 时间复杂度 | O(n×m) | O(n+m) |
| 空间复杂度 | O(1) | O(m) |
| 实现难度 | 简单 | 较复杂 |
| 适用场景 | 短字符串 | 长字符串 |
| 预处理 | 无 | 构建next数组 |

### 6.4 课程设计亮点

1. **模块化设计**：每个功能独立成模块，代码结构清晰
2. **多种匹配模式**：支持单次、重复、不重复三种匹配模式
3. **next数组可视化**：运行后输出next数组，便于理解算法原理
4. **交互式菜单**：用户友好，支持多种操作选择
5. **对比例子**：同时实现BF和KMP算法，可对比学习

## 二、项目详解

### 2.1 untitled - QML 基础入门

**目录结构**
```
untitled/
├── main.cpp          # C++ 入口，加载 QML 引擎
├── main.qml          # 主窗口，900x600 黑色背景
├── Next.qml          # 自定义 QML 组件（4色方块布局）
├── qml.qrc           # QML 资源文件
└── CMakeLists.txt    # CMake 构建配置
```

**main.cpp 模板**
```cpp
#include <QGuiApplication>
#include <QQmlApplicationEngine>

int main(int argc, char *argv[]) {
    QGuiApplication app(argc, argv);
    QQmlApplicationEngine engine;
    const QUrl url(QStringLiteral("qrc:/main.qml"));
    QObject::connect(&engine, &QQmlApplicationEngine::objectCreated,
        &app, [url](QObject *obj, const QUrl &objUrl) {
            if (!obj && url == objUrl) QCoreApplication::exit(-1);
        }, Qt::QueuedConnection);
    engine.load(url);
    return QGuiApplication::exec();
}
```

**学到的 QML 知识点**
- `Window`：窗口根元素，设置 width/height/visible/title/color
- `Rectangle`：矩形元素，设置 color/radius/rotation
- `anchors` 锚点布局：
  - `anchors.centerIn: parent` 居中
  - `anchors.left/anchors.top` 左对齐/顶对齐
  - `anchors.leftMargin` 边距控制
- `z` 属性：层叠顺序（数字越大越靠前）
- RGB 颜色：`"#rrggbb"` 十六进制格式
- 组件化：`Next.qml` 作为自定义组件在 `main.qml` 中直接使用

### 2.2 untitled1 - QML 布局进阶

**main.qml 核心代码**
```qml
import QtQuick.Layouts

Window {
    ColumnLayout {
        anchors.fill: parent
        Rectangle { Layout.fillWidth: true; height: 100; color: "yellow" }
        Rectangle { width: 100; height: 100; color: "blue" }
        Rectangle { width: 100; height: 100; color: "red" }
    }
}
```

**学到的布局知识**
- `ColumnLayout`：垂直排列子元素
- `Layout.fillWidth: true`：宽度填满父容器
- `anchors.fill: parent`：填满整个父元素
- 布局比锚点更灵活，适合多元素排列

### 2.3 cpp - C++ 与 QML 交互（重点）

这是最核心的项目，实现了 C++ 后端 + QML 前端的完整交互。

**架构设计**
```
QML 前端 (Main.qml)
    ↕ Q_PROPERTY 绑定
C++ 后端 (calc.h / calc.cpp)
    ↕ Q_OBJECT 元对象系统
信号槽通信
```

**calc.h 核心代码**
```cpp
class Calc : public QObject {
    Q_OBJECT
    Q_PROPERTY(int result READ result NOTIFY resultChanged FINAL)

private:
    int m_result = 0;

public:
    int result();
public slots:
    void add(int x, int y, int z);  // QML 可直接调用

signals:
    void resultChanged();  // 通知 QML 界面刷新
};
```

**calc.cpp 实现**
```cpp
void Calc::add(int x, int y, int z) {
    m_result = x + y + z;
    emit resultChanged();  // 触发信号，QML 自动更新
}
```

**main.cpp 注册 C++ 对象到 QML**
```cpp
Calc calc;
engine.rootContext()->setContextProperty("calc", &calc);
// QML 中可直接使用 calc.add(1,2,3)
```

**核心概念总结**

| 概念 | 作用 | 用法 |
|------|------|------|
| `Q_OBJECT` | 启用元对象系统 | 类声明必须加 |
| `Q_PROPERTY` | 暴露属性给 QML | `Q_PROPERTY(type name READ getter NOTIFY signal)` |
| `signals` | 定义信号 | 只需声明，无需实现，由 moc 自动生成 |
| `slots` | 定义槽函数 | QML 可直接调用 |
| `emit` | 发射信号 | 触发 QML 界面更新 |
| `setContextProperty` | 注册 C++ 对象到 QML | 在 `engine.rootContext()` 上调用 |

### 2.4 w - Qt Widgets 基础

**目录结构**
```
w/
├── main.cpp          # QApplication 入口
├── mainwindow.cpp    # 主窗口实现
├── mainwindow.h      # 主窗口头文件
├── mainwindow.ui     # Qt Designer UI 文件
└── CMakeLists.txt    # Qt Widgets 构建配置
```

**main.cpp 核心代码**
```cpp
#include "mainwindow.h"
#include <QApplication>

int main(int argc, char *argv[]) {
    QApplication a(argc, argv);
    MainWindow w;
    w.show();
    return QApplication::exec();
}
```

**mainwindow.cpp**
```cpp
MainWindow::MainWindow(QWidget *parent)
    : QMainWindow(parent), ui(new Ui::MainWindow) {
    ui->setupUi(this);  // 加载 UI 文件
}

MainWindow::~MainWindow() {
    delete ui;
}
```

**学到的 Widgets 知识**
- `QApplication` vs `QGuiApplication`：Widgets 用 QApplication，QML 用 QGuiApplication
- `QMainWindow`：主窗口基类，提供菜单栏、状态栏、工具栏
- `.ui` 文件：Qt Designer 可视化设计，自动生成 `ui_mainwindow.h`
- `Ui::MainWindow`：UI 文件生成的命名空间
- 国际化：`QTranslator` + `.ts` 翻译文件

## 三、Qt 核心概念总结

### 3.1 两种 GUI 框架对比

| 特性 | Qt Quick (QML) | Qt Widgets |
|------|----------------|------------|
| 语言 | QML + JavaScript | C++ |
| 布局 | 声明式 | 命令式 |
| 样式 | QML 样式绑定 | CSS/QSS |
| 动画 | 内置动画系统 | 需手动实现 |
| 适用 | 移动端/现代 UI | 桌面传统 UI |
| 学习曲线 | 前端友好 | C++ 友好 |

### 3.2 C++ 与 QML 通信流程

```
C++ → QML：
  1. Q_PROPERTY 暴露属性
  2. emit signal 通知界面更新

QML → C++：
  1. setContextProperty 注册对象
  2. QML 直接调用 C++ slot 方法
```

### 3.3 项目模板（CMake）

```cmake
cmake_minimum_required(VERSION 3.16)
project(myapp VERSION 0.1 LANGUAGES CXX)
set(CMAKE_CXX_STANDARD 17)

# QML 项目
find_package(Qt6 REQUIRED COMPONENTS Quick)
qt_add_executable(myapp main.cpp)
qt_add_qml_module(myapp URI myapp QML_FILES Main.qml)
target_link_libraries(myapp PRIVATE Qt6::Quick)

# Widgets 项目
find_package(Qt6 REQUIRED COMPONENTS Widgets)
add_executable(myapp main.cpp mainwindow.cpp mainwindow.h)
target_link_libraries(myapp PRIVATE Qt6::Widgets)
```

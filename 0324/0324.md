## 单链表
- 头插法:存储序列与逻辑序列是相反的;翻转链表,栈
- 尾插法 
```c
typedef struct Node
{
    char data;//数据域
    struct Node*next;//指针域 后继
    // struct Node*prev;//指针域 前驱
}node;

//定义链表 :头节点(哨兵节点) 尾指针
typedef struct list
{
    Node *head;//头节点,创建
    Node *tail;//尾指针,空表指向头节点,非空指向终端节点
}list;


```

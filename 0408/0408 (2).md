# 字符串匹配算法

## 串的定义
串是由零个或多个字符组成的有限序列，也称为字符串。

## 字符串匹配算法

### BF算法（暴力匹配算法）
BF算法是一种简单直观的字符串匹配算法，通过逐个比较子串和主串的字符来实现匹配。

```c
int bf(char *a, char *s, int a_len, int s_len)
{
    int i, j, k;

    for (i = 0; i <= a_len - s_len; i++)
    {
        k = i;
        for (j = 0; j < s_len; j++)
        {
            if (a[k] == s[j])
            {
                k++;
            }
            else
            {
                break;
            }
        }
        if (j == s_len)
        {
            return i;
        }
    }
    return -1;
}
```
- **时间复杂度**: O(m*n)，其中m是主串长度，n是子串长度
- **功能**: 在主串a中查找子串s的位置

### KMP算法
KMP算法是一种高效的字符串匹配算法，通过利用已经匹配的信息避免重复比较，提高匹配效率。

#### KMP算法实现
```c
int kmp(char *a, char *s, int *next, int s_len, int a_len)
{
    int i = 0, j = 0, k = 0;

    while (i < a_len && j < s_len)
    {
        if (j == -1 || a[i] == s[j])
        {
            i++;
            j++;
        }
        else
        {
            j = next[j];
        }
    }
    if (j == s_len)
    {
        return i - j;
    }
    else
        return -1;
}
```

#### 计算next数组
```c
// 方法1
next[0] = -1;
for (i = 1; i < s_len; i++)
{
    int temp = 0;
    for (j = 1; j <= i; j++)
    {
        int m = 1;
        for (k = 0; k < j; k++)
        {
            if (s[k] != s[(i + 1) - j + k])
            {
                m = 0;
                break;
            }
        }
        if (m)
            temp = j;
    }
    next[i] = temp;
}

// 方法2
next[0] = 0;
for (i = 1; i < s_len; i++)
{
    int temp = 0;
    for (j = 0; j < i; j++)
    {
        int m = 1, n = j;
        for (k = 0; k <= j; k++)
        {
            if (s[k] != s[i - n])
            {
                break;
            }
            if (s[k] == s[i - n] && n == 1)
            {
                temp = j;
            }
            n--;
        }
    }
    next[i - 1] = temp;
    printf("%d", temp);
}
```
- **时间复杂度**: O(m + n)，其中m是主串长度，n是子串长度
- **功能**: 利用next数组避免重复比较，提高匹配效率

### 辅助函数

#### 读取字符串
```c
int get(char *p, int len)
{
    while (1)
    {
        if (len > 0)
        {
            if (p[len - 1] == '\n')
            {
                p[len - 1] = '\0';
                break;
            }
        }

        p[len++] = getchar();
    }
    return len - 1;
}
```

#### 显示数组
```c
void show(int a[], int len)
{
    printf("{");
    for (int i = 0; i < len; i++)
    {
        printf("%d,", a[i]);
    }
    printf("\b}\n");
}
```

## 算法比较

| 算法 | 时间复杂度 | 空间复杂度 | 特点 |
|------|------------|------------|------|
| BF算法 | O(m*n) | O(1) | 简单直观，适用于小规模数据 |
| KMP算法 | O(m+n) | O(n) | 高效，适用于大规模数据 |

## 示例

### 输入输出示例
输入：
```
a b c a b d
c a b
```

输出：
```
{0,0,1}
2
```

解释：
- 主串："a b c a b d"
- 子串："c a b"
- next数组：{0, 0, 1}
- 匹配位置：2（从0开始计数）

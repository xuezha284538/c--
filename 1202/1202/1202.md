## 赋值
从右往左运算，右值：字面量、变量、表达式、函数

> 表达式：由操作数和运算符构成，2 + 3, a / 4, a - b * 2

操作数：左操作数、右操作数
一个运算符加两个操作数这样的运算符叫 `二元运算`，还有一元、三元

```c
    int x = 1, y = 3, z = 9;
    x = y = z = 1;
    // 逗号运算：从左往右
    x = 2, 3;
    // 把两条语句合并成为一条语句，譬如在 for ( ; ; )
    x = y + 1, y = 3;
```

## 算数运算

% 模运算只能是整数，
复数模运算的结果，看左操作数
-7 % 4  == -3
 7 % -4 == 3
-7 % -4 == -3

- `+`
- `-`
- `*`
- `/`
- `%`   模
- `++`  
- `--`

```c

    a = 4;
    // int b1 = a++;    // 后缀自增：先参与运算，再自增
    int b1 = a;
    a += 1;
    printf("a=%d, b1=%d\n", a, b1);
    
    a = 4;
    // int b2 = ++a;    // 前缀自增：先自增，再运算
    a += 1;
    int b2 = a;
    printf("a=%d, b2=%d\n", a, b2);

    int x = 1, y = 2;
    int z = ++x + y++;
    printf("x=%d,y=%d,z=%d\n", x, y, z);    // 2,3,4


    x = 2;
    z = ++x + x++;                  // 未定义行为
    printf("x=%d, z=%d\n", x, z);
```

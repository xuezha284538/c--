# git版本控制

## 版本控制工具
- cvs  集中式
- svn  集中式 只可以在线控制
- Git  分布式 可以离线控制 上线后同步状态

## git 命令
仓库: 一个文件夹 被初始化后,由git 托管
- 干净
- 未追踪
- 缓冲区
- 待提交



- `git init` 初始化仓库 会创造隐藏目录 .git
- `git status` 查看状态:干净,存在未追踪,待提交,待同步
- `git add` 把未追踪的文件加入缓冲区
- `git commit` 提交 以追踪 已经记录文件的改变,生成了日志
- `git push` 把本地记录同步到远程
- `git pull` 拉下来 把远程同步到本地
- `git fetch` 拉下来 把远程同步到本地   下载
- `git breach` 分支
- `git merge` 合并分支
- `git log` 查看日志
- `git checkout` 检出 ,回到过去某个版本

## 组合：整体与部分的关系 has-a
- 组合: 强组合，部分不能脱离整体存在，整体销毁部分销毁
- 聚合: 弱组合，部分可以独立存在，
- 关联: 存在联系，不是整体与部分

```c++
    // 属性对象：强组合，生命周期捆绑的，生命周期一致
    class Line
    {
        Point s;
        Point e;
    }
    // 指针：弱组合、聚合，生命周期独立
    class Line
    {
        Point *s;
        Point *e;
    }
    // 引用
    class Line
    {
        Point &s;
        Point &e;
    }
```

## 继承

角色
- 父类、基类、超类
- 子类、派生类：获得父类中的属性和行为

特性
- 代码重用：多个类公共的成员提取出来放入父类中，封装
- 易于维护和扩展：修改父类

类型
- 单继承
- 多继承：存在负作用

属性
- 子类拥有父类中所有属性：私有（不能之间访问，可通过构造函数初始化）、受保护、共有的
- 子类中可以访问父类的 受保护、共有的
- 受保护的属性子类可见

方法
- 子类可以覆盖父类中的方法，重写 override，父类的方法是虚函数
- 指针类型与对象类型不一致：父类的析构函数必须是虚的，否则子类的析构执行

## 多态

方法行为的多态，更具对象类型、参数类型、参数个数选择不同版本的方法执行，呈现不同的行为

- 重载：一个类内部，同名方法有多个版本，参数类型与参数个数不同，编译时选择不同方法执行
- 重写：在继承关系中，子类覆盖了父类的同名方法，更具对象的类型选择方法的不同版本


## 纯虚函数：抽象类、接口类

```c++
// oop2.cxx
#include <iostream>
#include <string>

using namespace std;

// 抽象类：包含纯虚函数的类，不能实例化，用来继承
// 抽象类：至少一个纯虚函数，可以包含具体函数
class Shape
{
private:
protected:
    string name;
public:
    Shape(): name("图形") {
        cout << "Shape()" << endl;
    }
    virtual ~Shape() {
        cout << "~Shape()" << endl;
    }
    // 纯虚函数
    virtual double area() = 0;
    // 具体
    void show()
    {
        cout << "图形的名称：" << name << endl;
    }
};

class Circle : public Shape
{
private:
    /* data */
public:
    Circle() {
        name = "圆形";
    }
    ~Circle() {}

    // 重写：纯虚函数
    double area() override
    {
        return 0;
    }
};

class Triagnle: public Shape
{
private:
    /* data */
public:
    Triagnle() {
        name = "三角形";
        cout << "Triagnle()" << endl;
    }
    ~Triagnle() {
        cout << "~Triagnle()" << endl;
    }

    double area()
    {
        return 0;
    }
};

int main(int argc, char const *argv[])
{
    Shape *s;

    s = new Circle();
    s->show();
    delete s;

    s = new Triagnle();
    s->show();
    delete s;

    return 0;
}

```

// oop3.cxx
// 接口类
#include <iostream>

// 接口类：特殊的抽象类：
// 1.所有函数都是纯虚函数
// 2.没有成员属性
class USB
{
public:
    virtual ~USB() = default;
    virtual void plugIn() = 0;
    virtual void run() = 0;
    virtual void pullOut() = 0;
};

class Player
{
public:
    virtual ~Player() = default;
    virtual void start() = 0;
    virtual void pause() = 0;
    virtual void run() = 0;
};

// 多继承
class MP3 : public USB, public Player
{
private:
    /* data */
public:
    MP3()
    {
        std::cout << "MP3()" << std::endl;
    }

    {
        std::cout << "~MP3()" << std::endl;

    {
        std::cout << "MP3 plugIn" << std::endl;

    void run()
    {
        std::cout << "MP3 run" << std::endl;
    }
    void pullOut()
    {
        std::cout << "MP3 pullOut" << std::endl;
    }

    void play()
    {
        plugIn();
        run();
        pullOut();
    }
};

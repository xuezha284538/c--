# C 语言学习仓库 (c--)

C 语言学习与练习记录，按日期目录组织。

## 目录结构

```
0107~1231/    按日期（月日）组织的每日练习
0808-http/    HTTP 服务器实现
0802/         HTTP 学习笔记（含 html 资料）
1118~1231/    年末练习
```

## 内容主题

- 指针 / 结构体 / 字符串（0107~0115）
- 链表 / 栈 / 队列（0319~0401）
- KMP 字符串匹配（0531）
- 文件 IO（0521、0525）
- 多线程 / 同步（0625~0628）
- Socket 编程（0703~0811）
- HTTP 服务器（0802、0808-http）
- 位运算（1219）

## 编译运行

每个目录下的 `.c` 文件可直接编译：

```bash
gcc 文件名.c -o 文件名 -lpthread
./文件名
```

网络相关示例可能需要链接 `-lpthread` 或 root 权限。

# 数据结构实现

## 链式栈（单链表实现）
链式栈是使用单链表实现的栈结构，采用头插法进行元素的入栈和出栈操作。

### 数据结构定义
```c
typedef struct node
{
    char data;
    struct node *next;

} node;

typedef struct list
{
    node *head;
    int len;
} stack;
```

### 操作函数

#### 初始化栈
```c
void init(stack *s)
{
    s->head = malloc(sizeof(node));
    s->head->next = NULL;
    s->len = 0;
}
```

#### 入栈
```c
void push(stack *s, char ch)
{
    node *new = malloc(sizeof(node));
    if (new == NULL)
    {
        // 处理内存分配失败
        return;
    }
    new->data = ch;
    new->next = s->head->next;
    s->head->next = new;
    s->len++;
}
```

#### 出栈
```c
char pop(stack *s)
{
     if (s->head->next == NULL) 
    {
        return '\0';  // 用字符表示错误
    }
    char ch = s->head->next->data;
    node *curren = s->head->next;
    s->head->next = s->head->next->next;
    free(curren);
    s->len--;
    return ch;
}
```

#### 获取栈顶元素
```c
char top(stack *s)
{
    if (s->head->next == NULL) 
    {
        // 处理空栈情况
        return '\0';  
    }
    return s->head->next->data;
}
```

#### 清空栈
```c
void clean(stack *s)
{
    node *new = s->head->next;
    while (new)
    {
        node *temp = new->next;
        free(new);
        new = temp;
    }
    s->head->next = NULL;
    s->len = 0;
}
```

#### 判断栈是否为空
```c
bool empty(stack *s)
{
    return s->len == 0;
}
```

#### 显示栈内容
```c
void show(stack *s)
{
    node *new = s->head->next;

    if (s->head->next == NULL)
    {
        printf("{}");
        return;
    }
    else
    {
        printf("{");
        while (new)
        {
            printf("%c,", new->data);
            new = new->next;
        }
        printf("\b}\n");
    }
}
```

#### 主函数示例
```c
int main()
{
    stack s;
    init(&s);
    push(&s, 'a');
    push(&s, '3');
    push(&s, 'a');
    push(&s, 'a');
    show(&s);
    pop(&s);
    show(&s);
    printf("%c\n", top(&s));
    
    if (empty(&s))
    {
        printf("空栈\n");
    }
    else
    {
        printf("非空栈\n");
        show(&s);
    }
    clean(&s);
    show(&s);
    return 0;
}
```

## 循环队列
循环队列是一种特殊的队列结构，使用数组实现，通过取模运算实现循环效果。

### 数据结构定义
```c
#define max 6

typedef struct queue
{
    char data[max];
    int head, tail;
} Queue;
```

### 操作函数

#### 初始化队列
```c
void init(Queue *q)
{
    q->head = 0;
    q->tail = 0;
}
```

#### 入队
```c
void enqueue(Queue *q, char ch)
{
    if (full(q))
    {
        printf("满了");
    }
    q->tail = (q->tail + 1) % max;
    q->data[q->tail] = ch;
}
```

#### 出队
```c
char denqueue(Queue *q)
{
    if (empty(q))
    {
        return;
    }
   q->head = (q->head + 1) % max;
    return q->data[q->head];
}
```

#### 判断队列是否已满
```c
bool full(Queue *q)
{
   if (empty(q))
   {
    return false;
   }
  return (q->tail + 1) % max == q->head;
}
```

#### 判断队列是否为空
```c
int empty(Queue *q)
{
    return (q->head == q->tail);
}
```

#### 获取队列大小
```c
int size(Queue *q)
{
    return (q->tail - q->head + max) % max;
}
```

#### 显示队列内容
```c
void show(Queue *q)
{
    if (empty(q))
    {
        printf("空的");
    }
    printf("{");
    for (int i = 0; i < size(q); i++)
    {
        int index = (q->head + 1 + i) % max;
        printf("%c,", q->data[index]);
    }
    printf("\b}\n");
}
```

#### 清空队列
```c
void clear(Queue *q)
{
    q->head = q->tail;
}
```

#### 主函数示例
```c
int main()
{
    Queue *q;
    init(q);
    enqueue(q, 'a');
    enqueue(q, '0');
    enqueue(q, '1');
    enqueue(q, '2');
    enqueue(q, '3');
    show(q);
    denqueue(q);
    denqueue(q);
    denqueue(q);
    enqueue(q, 'x');
    enqueue(q, 'y');
    enqueue(q, 'z');
    show(q);
    return 0;
}
```

## 时间复杂度分析

| 操作 | 链式栈 | 循环队列 |
|------|--------|----------|
| 初始化 | O(1) | O(1) |
| 入栈/入队 | O(1) | O(1) |
| 出栈/出队 | O(1) | O(1) |
| 获取栈顶/队首 | O(1) | O(1) |
| 清空 | O(N) | O(1) |
| 判断空/满 | O(1) | O(1) |
| 显示 | O(N) | O(N) |

# 循环单链表

## 循环单链表的定义
循环单链表是一种特殊的单链表，其尾节点的next指针指向头节点，形成一个闭合的环。

## 数据结构定义
```c
typedef struct Node
{
    char data;         // 数据域
    struct Node *next; // 指针域 后继
} node, Node;

// 链表结构
typedef struct clist
{
    struct Node *head; // 头指针
    struct Node *tail; // 尾指针    
    int len;           // 大小
} list, Clist;
```

## 操作函数

### 初始化链表
```c
void init(list *l)
{
    l->head = malloc(sizeof(Node));
    if(l->head == NULL)
    {
        return;
    }
    l->tail = l->head;
    l->head->next = l->head;
    l->len = 0;
}
```
- **时间复杂度**: O(1)
- **功能**: 创建头节点并初始化循环链表状态，头节点的next指针指向自身

### 添加元素（尾插法）
```c
void add(list *l, char ch)
{
    Node *new = malloc(sizeof(Node));
    new->data = ch;
    new->next = l->head; // 新节点指向头节点

    // 尾插法
    l->tail->next = new;
    l->tail = new;

    l->len++;
}
```
- **时间复杂度**: O(1)
- **功能**: 在链表尾部添加新元素

### 显示链表
```c
void show(list *l)
{
    Node *current = l->head->next;
    if(l->len < 1)
    {
        printf("{ }\n");
        return;
    }

    printf("{ ");
    while(current != l->head)
    {
        printf("%c,", current->data);
        current = current->next;
    }
    printf("}\b\n");
}
```
- **时间复杂度**: O(N)
- **功能**: 遍历并打印链表中的所有元素

### 清空链表
```c
void clear(list *l)
{
    Node *current = l->head->next;
    while(current == l->head)
    {
        Node *temp = current->next;
        free(current);
        current = temp;
    }
    free(l->head);
    init(l);
}
```
- **时间复杂度**: O(N)
- **功能**: 清空链表并释放内存，然后重新初始化

### 获取指定位置的节点
```c
Node *get(list *l, int index)
{
    Node *new = l->head;
    for(int i = 0; i < l->len; i++)
    {
        if(i == index)
        {
            return new;
        }
        new = new->next;
    }
    return l->head;
}
```
- **时间复杂度**: O(N)
- **功能**: 根据索引获取链表中的节点

### 插入元素
```c
void insert(list *l, int index, char ch)
{
    Node *new = malloc(sizeof(Node));
    new->data = ch;
    
    if(l->len == index - 1)
    {
        add(l, ch);
    }
    else
    {
        Node *prev = get(l, index - 1);
        new->next = prev->next;
        prev->next = new;
        l->len++;
    }
}
```
- **时间复杂度**: O(N)
- **功能**: 在指定位置插入新元素

## 主函数示例
```c
int main()
{
    list *List;
    init(List);
    add(List, '1');
    add(List, '2');
    add(List, '3');
    add(List, '4');
    
    show(List);
    printf("%c", get(List, 1)->data);
    insert(List, 5, 'h');
    show(List);
    
    clear(List);
    return 0;
}
```

## 循环单链表的优点
1. **循环遍历**: 可以从任意节点开始遍历整个链表
2. **尾节点操作方便**: 不需要遍历整个链表就能找到尾节点
3. **节省空间**: 相比双向链表，只需要一个指针域

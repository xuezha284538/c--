## HTTP 服务器：技术架构与实现步骤

HTTP HTML

- **描述**：支持 GET/HEAD/POST，实现文件目录浏览、断点续传（Range）、Keep-Alive、多线程/ epoll 事件驱动。
- **核心考察**：套接字编程、epoll/select、多线程同步、文件 I/O、HTTP 协议解析。
- **扩展**：添加简单 CGI 支持、日志系统、配置文件的热加载。

理解 HTTP 协议
使用 C 语言开发 HTTP 服务器，需要结合网络编程、HTTP 协议解析等知识，以下是其技术架构与核心开发步骤：


### 一、技术架构
HTTP 服务器的核心架构可分为 **五层**，从底层到上层依次为：
1. **网络层**：基于 TCP/IP 协议，负责建立和管理客户端与服务器的连接（使用 `socket`、`bind`、`listen`、`accept` 等系统调用）。
2. **连接管理层**：处理并发连接（如多线程、多进程或 I/O 多路复用，如 `select`/`epoll`），避免单连接阻塞。
3. **HTTP 协议解析层**：解析客户端发送的 HTTP 请求（如请求方法、URL、头部字段），并构建符合 HTTP 规范的响应（状态码、响应体）。
4. **业务逻辑层**：处理具体请求（如静态文件返回、动态接口处理），根据解析结果执行对应操作（如读取文件、调用函数）。
5. **资源管理层**：管理服务器资源（如文件缓存、连接池），优化性能（如限制并发数、缓存热门文件）。


### 二、开发步骤
#### 1. 初始化网络连接
- 创建 socket：使用 `socket(AF_INET, SOCK_STREAM, 0)` 创建 TCP 套接字。
- 绑定地址和端口：通过 `struct sockaddr_in` 配置 IP 和端口，调用 `bind()` 绑定。
- 监听连接：使用 `listen()` 设置监听队列长度，等待客户端连接。

  ```c
  int server_fd = socket(AF_INET, SOCK_STREAM, 0);
  struct sockaddr_in address;
  address.sin_family = AF_INET;
  address.sin_addr.s_addr = INADDR_ANY; // 监听所有网卡
  address.sin_port = htons(8080); // 端口 8080
  bind(server_fd, (struct sockaddr*)&address, sizeof(address));
  listen(server_fd, 10); // 最大等待连接数 10
  ```


#### 2. 处理并发连接
- 单线程循环：简单场景下，用 `accept()` 阻塞等待连接，处理完一个再接收下一个（仅适合低并发）。
- 多线程/多进程：每接收一个连接（`accept()` 返回客户端 socket），创建线程/进程处理，主线程继续等待新连接。
- I/O 多路复用：用 `epoll`（Linux）或 `select` 管理多个连接，非阻塞处理读写事件（适合高并发）。


#### 3. 解析 HTTP 请求
- 读取请求数据：通过客户端 socket 的 `recv()` 读取 HTTP 请求报文（如 `GET /index.html HTTP/1.1\r\n...`）。
- 解析请求行：提取请求方法（GET/POST）、URL（如 `/index.html`）、HTTP 版本。
- 解析请求头：提取 `Host`、`Content-Length` 等字段，用于后续处理（如判断是否为 POST 请求）。

  ```c
  char buffer[1024] = {0};
  recv(client_fd, buffer, 1024, 0); // 读取请求
  // 解析 buffer 中的请求行和头部
  ```


#### 4. 构建 HTTP 响应
- 根据请求处理结果，生成响应报文，包含：
  - 状态行：如 `HTTP/1.1 200 OK\r\n`。
  - 响应头：如 `Content-Type: text/html\r\n`、`Content-Length: 1024\r\n`。
  - 空行：`\r\n` 分隔头部和体。
  - 响应体：如 HTML 内容、文件数据。

  ```c
  char response[] = "HTTP/1.1 200 OK\r\n"
                    "Content-Type: text/html\r\n"
                    "\r\n"
                    "<h1>Hello, HTTP Server</h1>";
  send(client_fd, response, strlen(response), 0);
  ```


#### 5. 处理业务逻辑
- 静态文件服务：解析 URL 对应的文件路径（如 `/index.html` 对应 `./www/index.html`），读取文件内容并返回，若文件不存在返回 `404 Not Found`。
- 动态接口：若 URL 对应动态路径（如 `/api/get`），调用预设函数处理，生成 JSON 等响应体。


#### 6. 优化与扩展
- 并发优化：用 `epoll` 替代多线程，减少资源消耗；设置连接超时，避免无效连接占用资源。
- 安全加固：限制请求大小（防止大文件攻击）、过滤特殊字符（防止路径遍历漏洞，如 `../`）。
- 功能扩展：支持 HTTP 长连接（`Connection: keep-alive`）、Chunked 传输编码（用于动态生成内容）。


### 三、关键注意事项
- **协议规范**：严格遵循 HTTP 1.1 规范（如头部字段格式、状态码定义），否则客户端可能无法解析响应。
- **内存管理**：C 语言需手动管理内存（如 `malloc` 后 `free`），避免内存泄漏。
- **跨平台兼容**：不同系统的网络 API 可能有差异（如 Windows 用 `WSAStartup`，Linux 用 `socket`），需针对性处理。

通过以上步骤，可实现一个基础的 HTTP 服务器，后续可根据需求逐步完善功能（如 HTTPS 支持、负载均衡等）。

## FTP 服务器：技术架构与实现步骤

- **描述**：支持用户认证、文件上传/下载/删除/列表（LIST）、主动/被动模式、多用户并发。
- **核心考察**：套接字（控制连接 + 数据连接）、多线程/进程、状态机、文件权限处理。
- **扩展**：匿名登录、断点续传（REST）、速率限制。

使用 C 语言开发 FTP 服务器需基于 FTP 协议（RFC 959），结合 TCP 网络编程和文件操作，以下是技术架构与核心实现步骤：


### 一、技术架构
FTP 服务器采用 **“控制连接 + 数据连接”** 的双连接模式，整体架构分为五层：
1. **网络连接层**：基于 TCP 协议，管理控制连接（默认端口 21）和数据连接（动态端口或默认 20）的建立与关闭。
2. **协议解析层**：解析客户端发送的 FTP 命令（如 `USER`、`PASS`、`LIST`），并生成符合规范的响应码（如 220 服务就绪、530 认证失败）。
3. **认证与权限层**：处理用户登录（验证账号密码），管理文件操作权限（如读/写限制）。
4. **文件操作层**：执行具体文件操作（上传 `STOR`、下载 `RETR`、列表 `LIST` 等），通过数据连接传输文件数据。
5. **并发管理层**：采用多进程/多线程处理多个客户端连接，避免单连接阻塞。


### 二、实现步骤
#### 1. 初始化控制连接
- 创建控制 socket：使用 `socket(AF_INET, SOCK_STREAM, 0)` 创建 TCP 套接字，绑定 21 端口并监听。
- 循环等待客户端连接：通过 `accept()` 阻塞获取客户端控制连接，生成客户端 socket（用于后续命令交互）。

  ```c
  int control_fd = socket(AF_INET, SOCK_STREAM, 0);
  struct sockaddr_in server_addr, client_addr;
  server_addr.sin_family = AF_INET;
  server_addr.sin_addr.s_addr = INADDR_ANY;
  server_addr.sin_port = htons(21); // 控制端口 21
  bind(control_fd, (struct sockaddr*)&server_addr, sizeof(server_addr));
  listen(control_fd, 5); // 监听队列长度 5

  // 等待客户端连接
  socklen_t client_len = sizeof(client_addr);
  int client_fd = accept(control_fd, (struct sockaddr*)&client_addr, &client_len);
  ```


#### 2. 处理客户端连接（并发管理）
- 多进程模式：每接收到一个客户端连接（`client_fd`），`fork()` 子进程处理该客户端，父进程继续等待新连接（子进程退出后需回收资源）。
  ```c
  while (1) {
      int client_fd = accept(control_fd, ...);
      if (fork() == 0) { // 子进程
          close(control_fd); // 子进程关闭监听 socket
          handle_client(client_fd); // 处理客户端命令
          exit(0);
      } else {
          close(client_fd); // 父进程关闭客户端 socket
      }
  }
  ```


#### 3. 协议交互与认证
- 发送初始响应：连接建立后，发送 `220 Service ready` 通知客户端就绪。
- 处理登录命令：解析客户端发送的 `USER <username>` 和 `PASS <password>` 命令，验证账号密码（可从本地文件或数据库读取），成功返回 `230 Login successful`，失败返回 `530 Not logged in`。

  ```c
  // 示例：发送响应
  send(client_fd, "220 FTP Server Ready\r\n", 21, 0);
  
  // 读取客户端命令（如 "USER admin\r\n"）
  char cmd[1024];
  recv(client_fd, cmd, 1024, 0);
  // 解析命令并处理认证逻辑
  ```


#### 4. 数据连接管理
FTP 数据连接用于传输文件或目录列表，分为两种模式：
- **主动模式（PORT）**：客户端告知服务器数据连接的 IP 和端口（如 `PORT 192,168,1,100,10,20` 对应 `192.168.1.100:2580`），服务器主动连接该地址。
- **被动模式（PASV）**：服务器打开一个临时端口并告知客户端（如 `227 Entering Passive Mode (192,168,1,2,10,30)` 对应 `192.168.1.2:2590`），客户端主动连接该端口。

  ```c
  // 被动模式示例：服务器打开临时端口
  int data_fd = socket(AF_INET, SOCK_STREAM, 0);
  struct sockaddr_in data_addr;
  data_addr.sin_family = AF_INET;
  data_addr.sin_addr.s_addr = INADDR_ANY;
  data_addr.sin_port = 0; // 随机端口
  bind(data_fd, (struct sockaddr*)&data_addr, sizeof(data_addr));
  listen(data_fd, 1);
  // 获取随机端口并告知客户端
  ```


#### 5. 文件操作实现
- **列表（LIST）**：通过数据连接发送当前目录文件列表（调用 `opendir`、`readdir` 遍历文件，格式化后传输），完成后返回 `226 Transfer complete`。
- **下载（RETR）**：解析客户端请求的文件名（如 `RETR test.txt`），打开文件并通过数据连接发送内容，文件不存在返回 `550 File not found`。
- **上传（STOR）**：接收客户端通过数据连接发送的文件内容，写入本地文件（调用 `open`、`write`）。

  ```c
  // 下载文件示例
  int file_fd = open("test.txt", O_RDONLY);
  if (file_fd < 0) {
      send(client_fd, "550 File not found\r\n", 19, 0);
  } else {
      char buf[1024];
      int n;
      while ((n = read(file_fd, buf, 1024)) > 0) {
          send(data_fd, buf, n, 0); // 通过数据连接发送
      }
      close(file_fd);
      send(client_fd, "226 Transfer complete\r\n", 27, 0);
  }
  ```


#### 6. 优化与扩展
- **权限控制**：限制用户对目录的操作（如只读、禁止删除），通过 `chmod` 或自定义权限表实现。
- **连接超时**：设置控制连接超时时间（如 5 分钟无操作则断开），避免资源浪费。
- **错误处理**：对异常情况（如客户端突然断开）进行捕获，释放文件描述符和内存。


### 三、关键注意事项
- **协议细节**：严格遵循 FTP 命令格式（如命令以 `\r\n` 结尾）和响应码规则，否则客户端可能无法识别。
- **数据连接关闭**：每次文件操作后需关闭数据连接，控制连接保持打开（除非客户端发送 `QUIT`）。
- **跨平台兼容**：文件路径格式（如 Windows 用 `\`，Linux 用 `/`）和系统调用（如目录遍历函数）需适配不同 OS。

通过以上步骤，可实现一个基础的 FTP 服务器，支持用户登录、文件上传/下载、目录浏览等核心功能。

## 缓存服务器（redis）：技术架构与实现步骤

使用 C 语言实现缓存服务器需围绕“高效数据存储、快速查询、过期管理”核心目标，结合内存管理和网络通信，以下是技术架构与实现步骤：


### 一、技术架构
缓存服务器整体架构分为五层，核心是“键值对（Key-Value）”存储模型：
1. **网络层**：基于 TCP/UDP 协议接收客户端请求（如查询 `GET key`、存储 `SET key value`），返回处理结果。
2. **协议解析层**：解析客户端命令（如自定义文本协议或兼容 Redis 协议），验证格式合法性。
3. **缓存核心层**：
   - 数据结构：采用哈希表（Hash Table）存储键值对，支持 O(1) 级别的查询/插入/删除。
   - 过期策略：实现 LRU（最近最少使用）、TTL（存活时间）等策略，清理无效数据。
4. **内存管理层**：管理缓存占用的内存空间，设置最大内存限制，避免内存溢出。
5. **并发层**：使用多线程/IO 多路复用（`epoll`/`select`）处理多客户端并发请求。


### 二、实现步骤
#### 1. 定义数据结构与缓存核心
- **键值对结构**：包含键（字符串）、值（字符串或二进制数据）、过期时间（如 `expire` 字段）、访问时间（用于 LRU）。
  ```c
  typedef struct {
      char* key;          // 键
      char* value;        // 值
      size_t value_len;   // 值长度
      time_t expire;      // 过期时间（UNIX 时间戳，0 表示永不过期）
      time_t last_access; // 最后访问时间（用于 LRU）
  } CacheNode;
  ```

- **哈希表实现**：采用链地址法解决哈希冲突，每个桶存储链表头指针。
  ```c
  typedef struct HashBucket {
      CacheNode* head;    // 链表头
      int count;          // 桶内节点数
  } HashBucket;

  typedef struct {
      HashBucket* buckets; // 哈希桶数组
      int bucket_count;    // 桶数量（建议为质数，如 1021）
      int total_nodes;     // 总节点数
      size_t max_memory;   // 最大内存限制（字节）
      size_t used_memory;  // 当前使用内存
  } Cache;
  ```


#### 2. 初始化缓存与哈希表
- 创建缓存实例，初始化哈希桶，设置最大内存和过期策略。
  ```c
  Cache* cache_init(int bucket_count, size_t max_memory) {
      Cache* cache = malloc(sizeof(Cache));
      cache->bucket_count = bucket_count;
      cache->buckets = calloc(bucket_count, sizeof(HashBucket));
      cache->max_memory = max_memory;
      cache->used_memory = 0;
      cache->total_nodes = 0;
      return cache;
  }
  ```

- 实现哈希函数：将字符串键映射到哈希桶索引（如 DJB2 算法）。
  ```c
  unsigned int hash(const char* key) {
      unsigned int hash = 5381;
      int c;
      while ((c = *key++)) {
          hash = ((hash << 5) + hash) + c; // hash * 33 + c
      }
      return hash;
  }
  ```


#### 3. 核心缓存操作
- **插入数据（SET）**：计算键的哈希值，查找对应桶，若键已存在则更新值，否则新增节点；检查内存是否超限，若超限触发淘汰策略。
  ```c
  int cache_set(Cache* cache, const char* key, const char* value, size_t value_len, time_t expire) {
      unsigned int idx = hash(key) % cache->bucket_count;
      HashBucket* bucket = &cache->buckets[idx];
      
      // 检查键是否存在，存在则更新
      CacheNode* node = find_node(bucket, key);
      if (node) {
          // 释放旧值内存
          cache->used_memory -= node->value_len;
          free(node->value);
      } else {
          // 新增节点，检查内存
          if (cache->used_memory + value_len > cache->max_memory) {
              evict_nodes(cache); // 触发淘汰策略
          }
          node = create_node(key, value, value_len, expire);
          add_node_to_bucket(bucket, node); // 插入链表头部
          cache->total_nodes++;
      }
      
      // 更新值和内存
      node->value = strndup(value, value_len);
      node->value_len = value_len;
      node->expire = expire;
      node->last_access = time(NULL);
      cache->used_memory += value_len;
      return 0;
  }
  ```

- **查询数据（GET）**：根据键查找节点，检查是否过期，返回值或“不存在”标识。
  ```c
  CacheNode* cache_get(Cache* cache, const char* key) {
      unsigned int idx = hash(key) % cache->bucket_count;
      CacheNode* node = find_node(&cache->buckets[idx], key);
      
      if (node) {
          // 检查过期
          if (node->expire != 0 && node->expire < time(NULL)) {
              remove_node(cache, node); // 移除过期节点
              return NULL;
          }
          node->last_access = time(NULL); // 更新访问时间（LRU 用）
          return node;
      }
      return NULL;
  }
  ```

- **过期淘汰策略**：以 LRU 为例，遍历所有节点，淘汰最久未访问的节点。
  ```c
  void evict_nodes(Cache* cache) {
      CacheNode* lru_node = NULL;
      // 查找最久未访问的节点
      for (int i = 0; i < cache->bucket_count; i++) {
          CacheNode* node = cache->buckets[i].head;
          while (node) {
              if (!lru_node || node->last_access < lru_node->last_access) {
                  lru_node = node;
              }
              node = node->next;
          }
      }
      if (lru_node) {
          remove_node(cache, lru_node); // 移除节点并释放内存
      }
  }
  ```


#### 4. 网络通信与协议处理
- **创建服务器 socket**：绑定端口（如 6379，兼容 Redis 客户端），监听客户端连接。
  ```c
  int server_fd = socket(AF_INET, SOCK_STREAM, 0);
  struct sockaddr_in addr = {
      .sin_family = AF_INET,
      .sin_addr.s_addr = INADDR_ANY,
      .sin_port = htons(6379)
  };
  bind(server_fd, (struct sockaddr*)&addr, sizeof(addr));
  listen(server_fd, 10);
  ```

- **处理客户端请求**：使用 `epoll` 实现 IO 多路复用（高效处理多连接），解析命令并调用缓存接口。
  ```c
  int epfd = epoll_create1(0);
  struct epoll_event ev, events[1024];
  ev.events = EPOLLIN;
  ev.data.fd = server_fd;
  epoll_ctl(epfd, EPOLL_CTL_ADD, server_fd, &ev);

  while (1) {
      int nfds = epoll_wait(epfd, events, 1024, -1);
      for (int i = 0; i < nfds; i++) {
          if (events[i].data.fd == server_fd) {
              // 新客户端连接，加入 epoll 监听
              int client_fd = accept(server_fd, NULL, NULL);
              ev.data.fd = client_fd;
              epoll_ctl(epfd, EPOLL_CTL_ADD, client_fd, &ev);
          } else {
              // 处理客户端命令（如 "SET key value" 或 "GET key"）
              char buf[1024];
              int len = recv(events[i].data.fd, buf, 1024, 0);
              if (len <= 0) {
                  close(events[i].data.fd); // 断开连接
                  continue;
              }
              process_command(cache, events[i].data.fd, buf, len);
          }
      }
  }
  ```

- **协议解析**：以简单文本协议为例（如 `SET key value\r\n` 或 `GET key\r\n`），提取命令和参数。
  ```c
  void process_command(Cache* cache, int client_fd, char* buf, int len) {
      if (strncmp(buf, "SET ", 4) == 0) {
          // 解析 key 和 value（简化示例）
          char* key = buf + 4;
          char* value = strchr(key, ' ');
          if (value) {
              *value++ = '\0'; // 分隔 key 和 value
              value[strcspn(value, "\r\n")] = '\0'; // 移除换行
              cache_set(cache, key, value, strlen(value), 0); // 永不过期
              send(client_fd, "OK\r\n", 4, 0);
          }
      } else if (strncmp(buf, "GET ", 4) == 0) {
          char* key = buf + 4;
          key[strcspn(key, "\r\n")] = '\0';
          CacheNode* node = cache_get(cache, key);
          if (node) {
              send(client_fd, node->value, node->value_len, 0);
              send(client_fd, "\r\n", 2, 0);
          } else {
              send(client_fd, "NULL\r\n", 6, 0);
          }
      }
  }
  ```


#### 5. 内存管理与优化
- **内存限制**：每次插入数据前检查总内存，超过限制则触发淘汰策略。
- **定期清理过期数据**：启动后台线程，每隔一段时间（如 1 秒）遍历哈希表，删除过期节点。
  ```c
  void* expire_cleaner(void* arg) {
      Cache* cache = (Cache*)arg;
      while (1) {
          sleep(1);
          lock_cache(cache); // 加锁避免并发冲突
          clean_expired_nodes(cache); // 清理所有过期节点
          unlock_cache(cache);
      }
  }
  ```

- **避免内存泄漏**：删除节点时需释放 `key`、`value` 及节点本身的内存，更新 `used_memory` 统计。


### 三、关键注意事项
- **并发安全**：多线程操作哈希表时需加锁（如 `pthread_mutex_t`），避免数据竞争。
- **哈希表扩容**：当负载因子（总节点数/桶数量）过高（如 > 10），需扩容哈希表并重新哈希所有节点，减少冲突。
- **协议兼容性**：若需兼容现有客户端（如 Redis CLI），需实现对应协议（如 Redis 的 RESP 协议）。
- **性能优化**：使用内存池减少 `malloc`/`free` 开销，对频繁访问的节点采用“热点缓存”单独存储。

通过以上步骤，可实现一个基础的内存缓存服务器，支持键值对存储、过期淘汰和并发访问，适合作为分布式系统的本地缓存或简单中间件。

## wget/curl 工具：技术架构与实现步骤

使用 C 语言实现类似 `wget` 的命令行下载工具，核心是通过 HTTP/HTTPS 协议获取网络资源并保存到本地文件。以下是技术架构与实现步骤：


### 一、技术架构
`wget` 类工具的架构可分为四层，从网络请求到本地存储逐步处理：
1. **URL 解析层**：解析输入的 URL（如 `https://example.com/file.zip`），提取协议类型（HTTP/HTTPS）、域名、端口、路径等信息。
2. **网络连接层**：根据协议类型建立 TCP 连接（HTTP 直接连接，HTTPS 需通过 TLS/SSL 加密），与服务器通信。
3. **协议交互层**：构造 HTTP 请求（如 `GET` 方法），发送给服务器并接收响应，处理状态码（如 200 成功、404 不存在）。
4. **文件处理层**：从响应中提取文件数据，写入本地文件，支持断点续传（通过 `Range` 请求头实现）。


### 二、实现步骤
#### 1. 解析 URL
- 提取协议：判断 URL 开头是 `http://` 还是 `https://`，确定端口（HTTP 默认 80，HTTPS 默认 443）。
- 提取域名和路径：例如 `https://example.com/path/file.txt` 中，域名为 `example.com`，路径为 `/path/file.txt`。

  ```c
  // 简化的 URL 解析示例
  typedef struct {
      char* protocol; // "http" 或 "https"
      char* host;     // 域名/IP
      int port;       // 端口
      char* path;     // 资源路径
  } URL;

  URL* parse_url(const char* url) {
      URL* u = malloc(sizeof(URL));
      // 解析协议
      if (strstr(url, "https://") == url) {
          u->protocol = "https";
          u->port = 443;
          url += 8; // 跳过 "https://"
      } else {
          u->protocol = "http";
          u->port = 80;
          if (strstr(url, "http://") == url) url += 7;
      }
      // 解析 host 和 path（省略具体字符串处理逻辑）
      return u;
  }
  ```


#### 2. 建立网络连接
- **HTTP 连接**：直接通过 `socket` 建立 TCP 连接到目标主机的端口。
- **HTTPS 连接**：基于 TCP 连接，使用 OpenSSL 库进行 TLS 握手（`SSL_new`、`SSL_connect`），后续数据通过加密通道传输。

  ```c
  // HTTP 连接示例
  int create_http_socket(const char* host, int port) {
      struct hostent* hp = gethostbyname(host); // 解析域名到 IP
      int sockfd = socket(AF_INET, SOCK_STREAM, 0);
      struct sockaddr_in addr;
      addr.sin_family = AF_INET;
      addr.sin_port = htons(port);
      memcpy(&addr.sin_addr, hp->h_addr, hp->h_length);
      connect(sockfd, (struct sockaddr*)&addr, sizeof(addr));
      return sockfd;
  }

  // HTTPS 连接（依赖 OpenSSL）
  SSL* create_https_ssl(int sockfd) {
      SSL_CTX* ctx = SSL_CTX_new(TLS_client_method());
      SSL* ssl = SSL_new(ctx);
      SSL_set_fd(ssl, sockfd);
      SSL_connect(ssl); // 完成 TLS 握手
      return ssl;
  }
  ```


#### 3. 构造 HTTP 请求并接收响应
- 构造 `GET` 请求：包含请求行（`GET /path/file.txt HTTP/1.1`）、请求头（`Host: example.com`、`User-Agent: MyWget` 等）。
- 发送请求：通过 socket 或 SSL 通道发送请求数据。
- 解析响应：读取响应头，提取状态码（如 `HTTP/1.1 200 OK`）、`Content-Length`（文件大小）、`Content-Type` 等信息。

  ```c
  // 构造 HTTP 请求
  char* build_request(const char* path, const char* host) {
      char* req = malloc(1024);
      snprintf(req, 1024, 
          "GET %s HTTP/1.1\r\n"
          "Host: %s\r\n"
          "User-Agent: MyWget/1.0\r\n"
          "Connection: close\r\n"
          "\r\n", path, host);
      return req;
  }

  // 发送请求并读取响应头
  void send_request_and_parse(int sockfd, SSL* ssl, const char* req) {
      if (ssl) {
          SSL_write(ssl, req, strlen(req)); // HTTPS 发送
      } else {
          send(sockfd, req, strlen(req), 0); // HTTP 发送
      }

      // 读取响应头（简化：读取到空行 "\r\n\r\n" 为止）
      char buffer[4096] = {0};
      int n = ssl ? SSL_read(ssl, buffer, 4096) : recv(sockfd, buffer, 4096, 0);
      // 解析 buffer 中的状态码和头部字段
  }
  ```


#### 4. 下载文件并保存
- 提取文件名：从 URL 路径中获取（如 `/path/file.txt` 取 `file.txt`），或通过响应头 `Content-Disposition` 获取。
- 接收文件数据：响应头结束后，持续读取后续数据（HTTP 响应体），写入本地文件。
- 支持断点续传：若文件已部分下载，通过 `Range: bytes=xxx-` 请求头获取剩余部分，从文件末尾继续写入。

  ```c
  // 保存文件（简化版）
  void save_file(int sockfd, SSL* ssl, const char* filename, off_t start_pos) {
      int fd = open(filename, O_WRONLY | O_CREAT, 0644);
      if (start_pos > 0) {
          lseek(fd, start_pos, SEEK_SET); // 断点续传：移动到文件末尾
      }

      char buf[4096];
      int n;
      while (1) {
          // 读取数据（HTTP 用 recv，HTTPS 用 SSL_read）
          n = ssl ? SSL_read(ssl, buf, 4096) : recv(sockfd, buf, 4096, 0);
          if (n <= 0) break;
          write(fd, buf, n); // 写入文件
      }
      close(fd);
  }
  ```


#### 5. 断点续传实现
- 检查本地文件大小：若文件已存在，获取其大小（`lseek(fd, 0, SEEK_END)`）。
- 构造带 `Range` 的请求：`Range: bytes=10240-`（从 10240 字节处开始下载），服务器返回 `206 Partial Content` 表示支持。

  ```c
  // 断点续传请求头
  snprintf(req, 1024, 
      "GET %s HTTP/1.1\r\n"
      "Host: %s\r\n"
      "Range: bytes=%lld-\r\n" // 从已下载的位置继续
      ..., path, host, start_pos);
  ```


### 三、关键注意事项
- **协议兼容性**：处理 HTTP 1.1 的长连接、分块传输（`Transfer-Encoding: chunked`）等特殊情况。
- **错误处理**：对连接失败、404 错误、网络中断等情况进行捕获，输出友好提示。
- **HTTPS 依赖**：需链接 OpenSSL 库（编译时加 `-lssl -lcrypto`），实现加密传输。
- **进度显示**：通过 `Content-Length` 和已下载字节数计算进度（如 `50% [=====     ]`）。

通过以上步骤，可实现一个基础的 `wget` 功能，支持 HTTP/HTTPS 下载、断点续传和本地文件保存，满足简单的网络资源获取需求。

## gping：技术架构与实现步骤
在 Linux 终端中实现图形化的 ping 命令（类似 `ping` 但以可视化方式展示结果），核心是在终端内通过字符或简单图形实时显示网络延迟、丢包率等信息。以下是技术思路和实现方向：

## 源代码统计工具：技术架构与实现步骤

### C语言线程池的技术架构与实现步骤

线程池是一种多线程处理模式，它预先创建一定数量的线程并维护一个任务队列，当有新任务到来时，从线程池中获取一个空闲线程执行任务，执行完成后线程不会销毁而是返回线程池等待下一个任务。这种模式能够有效减少线程创建和销毁的开销，提高系统性能。

### 技术架构

一个完整的线程池通常包含以下组件：

1. **线程池结构体**：管理线程池的整体状态，包括线程数组、任务队列、锁和条件变量等。
2. **任务队列**：存储待执行的任务，支持线程安全的入队和出队操作。
3. **工作线程**：从任务队列中获取任务并执行。
4. **API接口**：提供线程池的初始化、任务提交、销毁等功能。

### 实现步骤

#### 1. 定义线程池和任务的数据结构

首先需要定义线程池和任务的数据结构，以及相关的状态常量：

```c
#include <stdio.h>
#include <stdlib.h>
#include <pthread.h>
#include <stdbool.h>

// 任务结构体
typedef struct Task {
    void (*function)(void*);  // 任务函数指针
    void* argument;           // 任务参数
    struct Task* next;        // 指向下一个任务的指针
} Task;

// 线程池结构体
typedef struct ThreadPool {
    pthread_t* threads;       // 线程数组
    Task* task_queue;         // 任务队列
    Task* queue_tail;         // 任务队列尾部指针
    pthread_mutex_t lock;     // 互斥锁，用于保护任务队列
    pthread_cond_t condition; // 条件变量，用于线程间通信
    int thread_count;         // 线程数量
    int queue_size;           // 当前任务队列大小
    bool shutdown;            // 线程池是否关闭
} ThreadPool;
```

#### 2. 实现线程池初始化函数

初始化线程池，创建指定数量的工作线程：

```c
// 工作线程函数
void* thread_worker(void* arg);

// 初始化线程池
ThreadPool* thread_pool_init(int thread_count) {
    // 分配线程池内存
    ThreadPool* pool = (ThreadPool*)malloc(sizeof(ThreadPool));
    if (!pool) {
        fprintf(stderr, "Error: Failed to allocate memory for thread pool\n");
        return NULL;
    }
    
    // 初始化线程池参数
    pool->thread_count = thread_count;
    pool->queue_size = 0;
    pool->task_queue = NULL;
    pool->queue_tail = NULL;
    pool->shutdown = false;
    
    // 初始化锁和条件变量
    if (pthread_mutex_init(&pool->lock, NULL) != 0 ||
        pthread_cond_init(&pool->condition, NULL) != 0) {
        fprintf(stderr, "Error: Failed to initialize mutex or condition variable\n");
        free(pool);
        return NULL;
    }
    
    // 分配线程数组内存
    pool->threads = (pthread_t*)malloc(sizeof(pthread_t) * thread_count);
    if (!pool->threads) {
        fprintf(stderr, "Error: Failed to allocate memory for threads\n");
        pthread_mutex_destroy(&pool->lock);
        pthread_cond_destroy(&pool->condition);
        free(pool);
        return NULL;
    }
    
    // 创建工作线程
    for (int i = 0; i < thread_count; i++) {
        if (pthread_create(&pool->threads[i], NULL, thread_worker, (void*)pool) != 0) {
            fprintf(stderr, "Error: Failed to create thread %d\n", i);
            // 已经创建的线程需要清理
            for (int j = 0; j < i; j++) {
                pthread_cancel(pool->threads[j]);
            }
            pthread_mutex_destroy(&pool->lock);
            pthread_cond_destroy(&pool->condition);
            free(pool->threads);
            free(pool);
            return NULL;
        }
    }
    
    return pool;
}
```

#### 3. 实现工作线程函数

工作线程函数从任务队列中获取任务并执行：

```c
// 工作线程主循环
void* thread_worker(void* arg) {
    ThreadPool* pool = (ThreadPool*)arg;
    
    while (1) {
        // 锁定任务队列
        pthread_mutex_lock(&pool->lock);
        
        // 等待任务队列中有任务或者线程池关闭
        while (pool->queue_size == 0 && !pool->shutdown) {
            pthread_cond_wait(&pool->condition, &pool->lock);
        }
        
        // 检查线程池是否关闭且任务队列为空
        if (pool->shutdown && pool->queue_size == 0) {
            pthread_mutex_unlock(&pool->lock);
            pthread_exit(NULL);
        }
        
        // 从任务队列中取出任务
        Task* task = pool->task_queue;
        if (task) {
            pool->task_queue = task->next;
            if (!pool->task_queue) {
                pool->queue_tail = NULL;
            }
            pool->queue_size--;
        }
        
        // 解锁任务队列
        pthread_mutex_unlock(&pool->lock);
        
        // 执行任务
        if (task) {
            task->function(task->argument);
            free(task);
        }
    }
    
    return NULL;
}
```

#### 4. 实现任务提交函数

向线程池的任务队列中添加新任务：

```c
// 向线程池提交任务
int thread_pool_submit(ThreadPool* pool, void (*function)(void*), void* argument) {
    if (!pool || !function) {
        return -1;
    }
    
    // 创建新任务
    Task* task = (Task*)malloc(sizeof(Task));
    if (!task) {
        return -1;
    }
    
    task->function = function;
    task->argument = argument;
    task->next = NULL;
    
    // 锁定任务队列
    pthread_mutex_lock(&pool->lock);
    
    // 检查线程池是否已关闭
    if (pool->shutdown) {
        pthread_mutex_unlock(&pool->lock);
        free(task);
        return -1;
    }
    
    // 将任务添加到队列
    if (!pool->task_queue) {
        pool->task_queue = task;
        pool->queue_tail = task;
    } else {
        pool->queue_tail->next = task;
        pool->queue_tail = task;
    }
    
    pool->queue_size++;
    
    // 通知等待的线程有新任务到来
    pthread_cond_signal(&pool->condition);
    
    // 解锁任务队列
    pthread_mutex_unlock(&pool->lock);
    
    return 0;
}
```

#### 5. 实现线程池销毁函数

安全地销毁线程池，等待所有任务完成并回收资源：

```c
// 销毁线程池
void thread_pool_destroy(ThreadPool* pool) {
    if (!pool) {
        return;
    }
    
    // 锁定任务队列
    pthread_mutex_lock(&pool->lock);
    
    // 标记线程池为关闭状态
    pool->shutdown = true;
    
    // 唤醒所有等待的线程
    pthread_cond_broadcast(&pool->condition);
    
    // 解锁任务队列
    pthread_mutex_unlock(&pool->lock);
    
    // 等待所有线程完成
    for (int i = 0; i < pool->thread_count; i++) {
        pthread_join(pool->threads[i], NULL);
    }
    
    // 清理资源
    pthread_mutex_destroy(&pool->lock);
    pthread_cond_destroy(&pool->condition);
    
    // 清理未执行的任务
    while (pool->task_queue) {
        Task* task = pool->task_queue;
        pool->task_queue = task->next;
        free(task);
    }
    
    // 释放内存
    free(pool->threads);
    free(pool);
}
```

#### 6. 使用示例

下面是一个简单的使用线程池的示例：

```c
// 示例任务函数
void example_task(void* arg) {
    int task_id = *(int*)arg;
    printf("Task %d is running on thread %lu\n", task_id, pthread_self());
    // 模拟任务执行
    sleep(1);
    printf("Task %d completed\n", task_id);
}

int main() {
    // 创建一个包含4个线程的线程池
    ThreadPool* pool = thread_pool_init(4);
    if (!pool) {
        return 1;
    }
    
    // 提交10个任务到线程池
    int task_ids[10];
    for (int i = 0; i < 10; i++) {
        task_ids[i] = i;
        thread_pool_submit(pool, example_task, &task_ids[i]);
    }
    
    // 等待一段时间，让任务有机会执行
    sleep(5);
    
    // 销毁线程池
    thread_pool_destroy(pool);
    
    return 0;
}
```

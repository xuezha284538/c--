## 一、C 语言基础

### 1.1 历史与标准（1122）
- **创始人**：丹尼斯·里奇（Dennis Ritchie）在开发 UNIX 时设计。
- **标准演进**：K&R → C89/90 → C99 → C11 → C17 → C23。
- **常用编译器**：GCC、MSVC、Clang、TCC、Intel。
- **编辑器/IDE**：VS Code、Vim、Dev C++、Xcode、Visual Studio、CLion。
- **语言特性**：C 是**静态类型**语言（变量类型在编译期确定）。

### 1.2 编译流程（1122 / 0115）
源文件 → **预处理** → **编译** → **链接** → 执行
- 预处理：展开宏、处理 `#include`、条件编译。
- 编译：生成目标文件 `.o`。
- 链接：合并目标文件与库，生成可执行文件。

### 1.3 数据类型（1122）
| 类别 | 说明 |
|------|------|
| 基本类型 | `char`、`short`、`int`、`long`、`long long`、`float`、`double`、`long double`、`_Bool`/`bool` |
| 组合类型 | 数组、结构体、联合体、枚举 |
| 指针类型 | `int*`、`char*` 等 |
| void 类型 | 无类型，常用于泛型指针与函数返回 |

### 1.4 进制与浮点数（1125）
- 二进制、八进制、十六进制 ↔ 十进制互转。
- 浮点数二进制表示：整数部分 + 小数部分分别处理。

### 1.5 运算符（1129）
- **算术**：`+ - * / %`，自增自减 `++` `--`（前缀/后缀区别）。
- **赋值**：`=` 及复合赋值 `+= -= *= /= %=`，多重赋值、逗号运算符。
- **关系**：`< > == != <= >=`，结果为 1（真）或 0（假）。
- **逻辑**：`|| && !`，**短路运算**特性。
- **三元**：`条件 ? 表达式1 : 表达式2`。
- **位运算**：`& | ^ ~ << >>`。

### 1.6 流程控制（1129）
- 顺序结构、分支结构、循环结构。
- 分支：`if` / `if-else` / `if-else if-else` / `switch-case`。

## 二、数组与字符串

### 2.1 数组（1202）
- 连续存储空间，存放**同类型**元素，索引 0~n-1。
- **随机访问**，时间复杂度 O(1)。
- 注意避免**越界访问**。

### 2.2 字符与字符编码（1202）
- `char` 与整型兼容。
- 编码：ASCII、GBK、GB2312、Unicode、UTF-8、UTF-16。
- 宽字符：`wchar_t`。

### 2.3 二维数组（1202）
- 数组的数组，支持多种初始化方式。
- 应用：杨辉三角算法。

### 2.4 字符串定义（0109）
- 两种定义方式：
  - **字符数组**：`char s[] = "hello";`（内容可修改）
  - **字符指针**：`char *s = "hello";`（指向常量字符串，不可修改）
- 二者在赋值和修改行为上不同。

### 2.5 字符串函数（0110）
| 函数 | 作用 |
|------|------|
| `strcpy` | 字符串复制 |
| `strcmp` | 字符串比较 |
| `strstr` | 子串查找 |
| `strchr` | 字符查找 |
| `strtok` | 字符串分割 |

- 终端读取：`scanf`、`gets`（不安全）、`fgets`（推荐）。

## 四、指针

### 4.1 指针基础（0107 / 1219）
- 指针是存储其他变量**地址**的数据类型。
- 语法：`类型 * 变量名`（如 `int*`、`char*`、`double*`、`void*`）。
- 取地址 `&`，解引用 `*`。
- **野指针**：指向未知内存；**空指针**：`NULL`，指向空。

### 4.2 指针运算（0107）
- 指针加减法按数据类型大小移动。
- 数组名与指针的关系（数组名即首元素地址）。

### 4.3 常量指针与指针常量（0107）
- `const int *p`：常量指针，指向的数据不可变。
- `int *const p`：指针常量，指针本身不可变。

### 4.4 指针与函数（0107）
- 函数返回指针。
- 通过指针参数修改实参（如交换两个值）。
- 减少内存开销，用于数组遍历与操作。

### 4.5 void* 指针（0112）
- 通用指针，可指向任意类型数据，使用前需强制转换。
- 区别于空指针（`NULL`）与野指针。

### 4.6 指针进阶（1231）
- 多级指针、指针与数组、函数指针等。

## 七、数据结构

### 7.1 顺序表（0320）
- 基于数组的线性表实现。
- 操作：初始化、获取元素、插入、删除。

### 7.2 单链表（0320）
- 节点定义（数据 + 指针）。
- 操作：初始化、创建、获取、插入、删除。

### 7.3 双链表（0325）
- 节点含前驱和后继指针。
- 操作：尾插、获取、插入、删除、**翻转**（交换前后指针）、清空。

### 7.4 循环单链表（0328）
- 尾节点指向头节点，形成环。
- 操作：初始化（头节点指向自身）、尾插、显示、清空、获取、插入。

### 7.5 栈

#### 顺序栈（0331）
- 数组 + 栈顶指针（初始 -1）。
- 操作：入栈（判满）、出栈（判空）、获取栈顶、清空、判空。

#### 链式栈（0401）
- 头插法实现，头节点后的第一个节点为栈顶。
- 操作：入栈、出栈、获取栈顶、清空、判空。

### 7.6 队列

#### 循环队列（0401）
- 数组实现，头尾指针通过取模实现循环。
- 判满条件、判空条件、获取大小。

### 7.7 树（0411）

#### 二叉树
- 概念、术语、性质。
- 存储结构：顺序存储、链式存储。
- 遍历：前序、中序、后序、层次。
- 基本操作：创建、计算深度、节点数、叶子节点数。

#### 二叉搜索树（BST）
- 左 < 根 < 右。
- 操作：查找、插入、删除。

#### 平衡二叉树（AVL）
- 平衡因子定义。
- 旋转操作：左旋、右旋。

### 7.8 堆（0414 / 0428）
- **完全二叉树**，逻辑结构为二叉树，存储结构为数组。
- 应用：堆排序、优先级队列。

## 八、算法

### 8.1 字符串匹配

#### BF 算法（0408）
- 暴力匹配，逐字符比较，主串指针会回退。
- 时间复杂度 O(m×n)。

#### KMP 算法（0408 / 0524 / 0525）
- **主串指针不回退**，核心是 `next` 数组。
- `next` 数组基于**最长公共前后缀**构建。
- 回溯机制：`j = next[j]`。
- 时间复杂度 O(m+n)。
- 支持**多次匹配**（允许/不允许重叠）。

### 8.2 哈夫曼编码（0418 / 0421 / 0423 / 0429）
- 基于字典的压缩算法。
- 哈夫曼树是压缩算法的核心结构。
- 与二叉搜索树关联。

### 8.3 其他经典算法（0319 / 0331）
- **斐波那契数列**：递归与循环实现。
- **最大公约数**。
- **异或交换**：三步完成两整数交换。
- **回文判断**：快慢指针找中点 + 链表翻转。
- **荷兰国旗问题**：三指针法对 0/1/2 排序。
- **成绩等级判定**、**日期计算**。

## 十一、进阶主题

### 11.1 Base64 编解码（0605）
- 使用 OpenSSL 库实现。
- BIO（Base64 过滤器 + 内存流）操作。
- 支持字符串与文件级别的编码解码。

### 11.2 多线程编程（0612 / 0617）

#### 线程基础（0612）
- `pthread_create` 创建线程，`pthread_join` 等待。
- **分离态与非分离态**区别。

#### 线程同步（0617）
- **信号量**：初始化与 p/v 操作。
- 锁类型：互斥锁、自旋锁等。

### 11.3 网络编程

#### 基础（0625 / 0628）
- 网络拓扑、协议栈。
- **TCP**：面向连接、可靠传输。
- **UDP**：无连接、不可靠、高效。
- **大小端转换**：`htons`、`htonl`、`ntohs`、`ntohl`。

#### 架构与字节序（0703）
- **C/S 架构**：客户端/服务器端。
- **B/S 架构**：浏览器/服务器端。
- 端口号范围：2^16 = 65536，前 1014 保留。

#### TCP 套接字流程（0628 / 0707）
- 服务器：`socket` → `bind` → `listen` → `accept` → `read/write` → `close`。
- 客户端：`socket` → `connect` → `read/write` → `close`。

#### UDP 套接字（0706）
- `send` / `recv` 操作流程。
- 常用命令：`netstat`、`ps`、`kill` 等。
